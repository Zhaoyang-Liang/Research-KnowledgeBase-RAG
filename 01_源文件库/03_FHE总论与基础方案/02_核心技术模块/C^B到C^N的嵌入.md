## 一、符号与背景回顾

- \(N\) 是 2 的幂（CKKS 的环维数）。
- \(n\) 和 \(B\) 都是 \(N\) 的真因子，且 \(n \ge B\)。
- 编码函数 \(\operatorname{Ecd}_n : \mathbb{C}^n \to \mathbb{Z}[X]/(X^N+1)\) 定义为：
  \[
  \operatorname{Ecd}_n(\mathbf{z}) = \left\lfloor \Delta \cdot \tau_n^{-1}(\mathbf{z}) \right\rfloor,
  \]
  其中 \(\tau_n: \mathbb{R}[Y]/(Y^{2n}+1) \to \mathbb{C}^n\)，\(\tau_n(p) = (p(\zeta_{n,i}))_{i=0}^{n-1}\)，\(\zeta_{n,i} = \exp(2\pi \mathrm{I} \cdot 5^i / (4n))\)。
- 为了把结果放进 \(\mathbb{Z}[X]/(X^N+1)\)，我们做代换 \(Y = X^{N/(2n)}\)。因此，编码后的多项式是 \(X\) 的多项式，次数小于 \(N\)。

---

## 二、为什么 \(\operatorname{Ecd}_n(\mathbf{z}_0) = \operatorname{Ecd}_B(\mathbf{z}_1)\)？

这里 \(\mathbf{z}_1 \in \mathbb{C}^B\)，\(\mathbf{z}_0 = (\mathbf{z}_1,\mathbf{z}_1,\dots,\mathbf{z}_1)\) 是 \(\mathbf{z}_1\) 重复 \(n/B\) 次得到的向量（长度为 \(n\)）。

### 1. 从逆变换的角度看 \(\tau_n^{-1}\)

\(\tau_n\) 是多项式求值映射，它的逆 \(\tau_n^{-1}\) 是一个**插值**过程：给定 \(n\) 个复数 \(z_0,\dots,z_{n-1}\)，存在唯一一个实系数多项式 \(p(Y)\)，次数 \(< 2n\)，使得 \(p(\zeta_{n,i}) = z_i\)。这个多项式可以用离散傅里叶变换（DFT）公式表达（本质是IDFT）。

对于 \(\mathbf{z}_0\)，它的第 \(i\) 个分量等于 \(\mathbf{z}_1\) 的第 \((i \bmod B)\) 个分量。这种**周期为 \(B\)** 的向量在傅里叶分析中有一个重要性质：它的 DFT（在 \(n\) 个点上）只有那些频率是 \(n/B\) 的倍数的分量非零。换句话说，插值得到的多项式 \(p(Y)\) 实际上只包含 \(Y\) 的指数是 \(n/B\) 的倍数的项。

**形式化：**  
设 \(M = n/B\)（整数）。则 \(\mathbf{z}_0\) 的第 \(i\) 个分量 = \(\mathbf{z}_1\) 的第 \((i \bmod B)\) 个分量。那么：
\[
p(Y) = \sum_{j=0}^{2n-1} a_j Y^j
\]
满足 \(p(\zeta_{n,i}) = z_{0,i}\)。可以证明，当 \(i \mapsto \zeta_{n,i}\) 是 \(4n\) 次单位根的子集时，这种周期性导致 \(a_j = 0\) 除非 \(j\) 是 \(M\) 的倍数。因此 \(p(Y)\) 可以写成：
\[
p(Y) = \sum_{t=0}^{2B-1} a_{tM} Y^{tM} = q(Y^M)
\]
其中 \(q(Z)\) 是一个次数 \(< 2B\) 的多项式。

### 2. 变量替换回到 \(X\)

我们有两层变量：
- 编码 \(\operatorname{Ecd}_n(\mathbf{z}_0)\) 时：先得 \(p(Y)\)，再令 \(Y = X^{N/(2n)}\)。于是
  \[
  p(X^{N/(2n)}) = q\big((X^{N/(2n)})^{M}\big) = q\big(X^{M N/(2n)}\big).
  \]
  由于 \(M = n/B\)，所以 \(M N/(2n) = (n/B)\cdot N/(2n) = N/(2B)\)。

- 编码 \(\operatorname{Ecd}_B(\mathbf{z}_1)\) 时：原本使用 \(\tau_B^{-1}(\mathbf{z}_1)\)，得到多项式 \(q(Z)\)（次数 \(<2B\)），然后令 \(Z = X^{N/(2B)}\)，得到 \(q(X^{N/(2B)})\)。

因此两者完全相同：都是 \(q(X^{N/(2B)})\)。所以
\[
\operatorname{Ecd}_n(\mathbf{z}_0) = \operatorname{Ecd}_B(\mathbf{z}_1).
\]

### 3. 具体例子（数值化）

取 \(N=16\)，假设 \(n=4, B=2\)。那么 \(M=n/B=2\)。  
- \(\mathbf{z}_1 = (c_0, c_1) \in \mathbb{C}^2\)，则 \(\mathbf{z}_0 = (c_0,c_1,c_0,c_1)\)。  
- 插值点 \(\zeta_{4,i} = \exp(2\pi \mathrm{I} \cdot 5^i /16)\)，\(i=0,1,2,3\)。  
- 周期为2的特点使得插值多项式 \(p(Y)\) 只有 \(Y^0, Y^2, Y^4, Y^6\) 项（即指数偶数）。  
- 令 \(Y = X^{N/(2n)} = X^{16/8}=X^2\)，则 \(p(X^2) = q(X^4)\)。  
- 而 \(\operatorname{Ecd}_2(\mathbf{z}_1)\)：用 \(Y' = X^{N/(2B)} = X^{16/4}=X^4\)，得到 \(q(X^4)\)。所以相等。

## 三、代数含义：\(\mathbb{C}^B\) 是 \(\mathbb{C}^n\) 的子环

### 1. 将 \(\mathbb{C}^B\) 嵌入 \(\mathbb{C}^n\)

定义映射 \(\iota: \mathbb{C}^B \hookrightarrow \mathbb{C}^n\)：
\[
\iota(\mathbf{z}_1) = (\underbrace{\mathbf{z}_1, \mathbf{z}_1, \dots, \mathbf{z}_1}_{M \text{ 次}})
\]
\(\iota\) 是单射，且：
- \(\iota(\mathbf{u}+\mathbf{v}) = \iota(\mathbf{u}) + \iota(\mathbf{v})\)（加法分量对应）
- \(\iota(\mathbf{u} \odot \mathbf{v}) = \iota(\mathbf{u}) \odot \iota(\mathbf{v})\)（逐分量乘积）

因此 \(\iota\) 是一个**环同态**（从 \(\mathbb{C}^B\) 带 Hadamard 积到 \(\mathbb{C}^n\) 带 Hadamard 积）。它的像 \(\operatorname{Im}(\iota)\) 是 \(\mathbb{C}^n\) 的一个子环。这个子环恰好就是所有“周期为 \(B\)”的向量构成的集合。

### 2. 编码保持这个嵌入

我们刚刚证明了：
\[
\operatorname{Ecd}_n(\iota(\mathbf{z}_1)) = \operatorname{Ecd}_B(\mathbf{z}_1).
\]
也就是说，把 \(\mathbf{z}_1\) 先嵌入再编码，与直接编码 \(\mathbf{z}_1\) 得到的结果相同。因此，在加密层面上，密文无法区分一个 \(\mathbf{z}_1\) 和它的嵌入版本 \(\iota(\mathbf{z}_1)\)。这意味着我们可以“安全地”把低维向量当作高维向量的特殊子集来处理，而不会影响同态计算的结果。

### 3. 实际用途

这个性质在 CKKS 中极其有用：
- 比如你想计算很多个独立的小向量的 Hadamard 积，可以先把它们嵌入成大向量（重复），然后一次性做高维乘法，最后再把结果解包出来。这样减少了密文数量和旋转次数。
- 在 PaCo 论文中，这个子环结构用于将多个多项式的系数“打包”进一个密文的不同槽中，从而利用并行性。

### 4. 重新强调“子环”的含义

- 环的结构：加法是分量加法，乘法是分量乘法（Hadamard 积）。
- \(\mathbb{C}^B\) 作为子环：它的像在加法和乘法下封闭，并且继承相同的运算规则。
- 编码是环同态（近似）：\(\operatorname{Ecd}_n(\iota(\mathbf{u}) \odot \iota(\mathbf{v})) \approx \operatorname{Ecd}_n(\iota(\mathbf{u} \odot \mathbf{v}))\)，结合嵌入等式，可以推导出 \(\operatorname{Ecd}_B(\mathbf{u} \odot \mathbf{v}) \approx \operatorname{Ecd}_B(\mathbf{u}) \times \operatorname{Ecd}_B(\mathbf{v})\)，这正是 CKKS 的明文乘法性质。

## 四、总结

- **等式成立的原因**：重复向量的逆傅里叶变换（插值多项式）只有某些指数项，经过变量替换后与低维编码完全吻合。
- **子环的意义**：重复向量构成 \(\mathbb{C}^n\) 的一个子环，且编码在这个嵌入下保持一致，因此我们可以安全地利用低维结构进行高效同态计算。

你指出的问题很关键。原文中 \(t\) 从 \(0\) 到 \(2M-1\) 的范围是**错误的**，正确的范围应该是 \(0\) 到 \(2B-1\)（其中 \(B = n/M\)）。下面我给出正确的推导和改写方式。

---

## 1. 符号澄清

- \(n\)：高维向量长度  
- \(B\)：低维向量长度（\(B \le n\)）  
- \(M = n/B\)：重复次数（整数）  
- \(p(Y)\) 是 \(\tau_n^{-1}(\mathbf{z}_0)\) 得到的实系数多项式，次数 \(< 2n = 2MB\)  
- 周期性条件使得 \(p(Y)\) 只有指数为 \(M\) 的倍数的项非零  

因此：
\[
p(Y) = \sum_{k=0}^{2B-1} a_{kM} Y^{kM}
\]
其中 \(k\) 是整数，最大为 \(2B-1\)，因为 \(kM \le (2B-1)M = 2n - M < 2n\)。

---

## 2. 改写成 \(Z = Y^M\) 的形式

令 \(Z = Y^M\)，则 \(Y^{kM} = Z^k\)。于是：
\[
p(Y) = \sum_{k=0}^{2B-1} a_{kM} Z^k =: q(Z)
\]
这里 \(q(Z)\) 是一个关于 \(Z\) 的多项式，次数 \(< 2B\)。注意 \(Z\) 的幂次 \(k\) 与原来的指数 \(Y\) 的指数 \(kM\) 相对应，系数是 \(a_{kM}\)。

---

## 3. 下标和求和范围的变化总结

| 原表达式 | 新表达式 |
|---------|----------|
| 变量 \(Y\) | 变量 \(Z = Y^M\) |
| 指数 \(kM\) | 指数 \(k\) |
| 系数下标 \(kM\) | 系数下标 \(k\)（但注意实际存储的系数是原来的 \(a_{kM}\)） |
| 求和范围 \(k = 0, 1, \dots, 2B-1\) | 相同范围 \(k = 0, 1, \dots, 2B-1\) |

所以正确的写法是：
\[
p(Y) = \sum_{k=0}^{2B-1} \tilde{a}_k Z^k, \quad \text{其中 } \tilde{a}_k = a_{kM}, \quad Z = Y^M.
\]

---

## 4. 原文为什么会出现 \(2M\)？

原文作者很可能混淆了符号：他们可能用 \(M\) 表示 \(n/B\)（即重复次数），但错误地认为多项式次数上限是 \(2M\) 而不是 \(2B\)。实际上 \(p(Y)\) 的最高可能指数是 \(2n-1 = 2MB-1\)，因此非零指数 \(kM\) 中 \(k\) 的最大值是 \(2B-1\)，不是 \(2M-1\)。除非 \(B = M\)（即 \(n = B^2\)），否则这两个范围不同。原文的“次数 \(< 2M\)”显然是笔误，在我们理解时应纠正为“次数 \(< 2B\)”。
