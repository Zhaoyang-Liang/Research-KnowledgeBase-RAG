“共轭版本”我说得不严谨，正式说法叫：

**共轭元素**，英文是 **conjugate**。

它的意思是：

> 一个数如果是某个有理系数多项式的根，那么这个多项式的其他根，就是它的共轭。

关键是：这个多项式通常指它的 **最小多项式**。

---

## 1. 从 (\sqrt 2) 看

[
\sqrt 2
]

满足：

[
X^2-2=0
]

这个方程有两个根：

[
\sqrt 2,\quad -\sqrt 2
]

所以：

[
\sqrt 2
]

的共轭是：

[
-\sqrt 2
]

更完整地说，(\sqrt2) 的两个共轭值是：

[
\sqrt2,\quad -\sqrt2
]

如果一个数是：

[
a=3+5\sqrt2
]

那么它的共轭版本就是把里面的 (\sqrt2) 换成 (-\sqrt2)：

[
3+5\sqrt2
]

和：

[
3-5\sqrt2
]

所以这里的“共轭版本”就是：

[
\sqrt2 \mapsto -\sqrt2
]

后得到的另一个值。

---

## 2. 从 (i) 看

[
i
]

满足：

[
X^2+1=0
]

这个方程有两个根：

[
i,\quad -i
]

所以 (i) 的共轭是 (-i)。

如果：

[
a=4+7i
]

它的两个共轭版本是：

[
4+7i
]

和：

[
4-7i
]

这就是你熟悉的 **复共轭**。

但要注意：**复共轭只是共轭元素的一种特殊情况**。
更一般的共轭不一定只是把 (i) 变成 (-i)，也可以是把 (\sqrt[3]{2})、(\zeta_m) 等换成它们的其他根。

---

## 3. 从 (\zeta_m) 看

论文里用的是：

[
\zeta_m
]

它是本原 (m) 次单位根。

它的最小多项式是：

[
\Phi_m(X)
]

这个多项式的根是：

[
\zeta_m^a
]

其中：

[
\gcd(a,m)=1
]

所以 (\zeta_m) 的共轭就是：

[
\zeta_m^a,\quad a\in \mathbb Z_m^*
]

例如：

[
m=8
]

则：

[
\mathbb Z_8^*={1,3,5,7}
]

所以 (\zeta_8) 的共轭是：

[
\zeta_8,\quad \zeta_8^3,\quad \zeta_8^5,\quad \zeta_8^7
]

如果一个元素是：

[
x=2+3\zeta_8
]

那么它的共轭版本有四个：

[
2+3\zeta_8
]

[
2+3\zeta_8^3
]

[
2+3\zeta_8^5
]

[
2+3\zeta_8^7
]

---

## 4. “共轭版本”到底是在替换什么？

如果：

[
K=\mathbb Q(\alpha)
]

里面的元素一般长这样：

[
f(\alpha)
]

其中 (f) 是有理系数多项式。

如果 (\alpha) 的共轭根是：

[
\alpha_1,\alpha_2,\ldots,\alpha_d
]

那么：

[
f(\alpha)
]

的共轭版本就是：

[
f(\alpha_1),\quad f(\alpha_2),\quad \ldots,\quad f(\alpha_d)
]

也就是：**把生成元 (\alpha) 换成它的其他共轭根。**

---

## 5. 为什么共轭要用“有理系数多项式”定义？

因为我们研究的是：

[
K/\mathbb Q
]

也就是“相对于有理数 (\mathbb Q)”的数域。

所以有理数必须保持不变。

例如：

[
3+5\sqrt2
]

做共轭时，(3) 和 (5) 不变，只有 (\sqrt2) 换成 (-\sqrt2)：

[
3+5\sqrt2 \mapsto 3-5\sqrt2
]

这就是“相对于 (\mathbb Q)”的共轭。

---

## 6. 共轭和 trace 的关系

trace 就是把所有共轭版本加起来。

例如：

[
x=3+5\sqrt2
]

它的两个共轭版本是：

[
3+5\sqrt2,\quad 3-5\sqrt2
]

所以：

[
\operatorname{Tr}(x)
====================

(3+5\sqrt2)+(3-5\sqrt2)=6
]

再比如：

[
x=4+7i
]

两个共轭版本是：

[
4+7i,\quad 4-7i
]

所以：

[
\operatorname{Tr}(x)=8
]

---

一句话：

> **共轭版本就是：把一个代数数里的生成元，替换成它的最小多项式的其他根后得到的值。**
