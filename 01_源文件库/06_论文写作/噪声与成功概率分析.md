可以分析，但结论不是“肯定会成功”。更准确地说：

[
\boxed{
\text{可以给出理论噪声上界和失败概率上界，但通常会非常保守。}
}
]

对于 CKKS bootstrapping，尤其是 EvalMod，这个问题本来就不是完全干净的闭式分析。已有论文也承认 EvalMod 的理论复杂度/所需多项式次数很难精确决定，一个主要原因就是缺少精确的 (L_1) 噪声分析。

所以你论文里最好写成：

[
\boxed{
\text{correctness is probabilistic and parameter-dependent, not unconditional.}
}
]

也就是：只要噪声、近似误差、rounding error、EvalMod 输入范围都在预算内，就成功；否则可能失败。

---

# 1. CKKS bootstrapping 的“失败”到底是什么？

CKKS 是近似计算，所以它不像 BFV/BGV 那样只有“解密对/错”的二值概念。CKKS 的失败通常有两层意思。

## 1.1 精度失败

最终输出：

[
\Dec(\ct_{\mathrm{out}})=m+e_{\mathrm{out}}.
]

如果：

[
|e_{\mathrm{out}}|*{\infty}\le \varepsilon*{\mathrm{target}},
]

我们认为 bootstrapping 成功。

如果：

[
|e_{\mathrm{out}}|*{\infty}>\varepsilon*{\mathrm{target}},
]

则输出仍然可能“看起来有数”，但精度不够。这是 CKKS 的普通 precision failure。

---

## 1.2 EvalMod 失败

更严重的是 EvalMod 的输入超出近似区间。

CKKS ModUp 会把 plaintext 从：

[
m
]

变成：

[
m+q_0 I.
]

然后 EvalMod 需要在 slots 上近似 modular reduction，把：

[
m_i+q_0 I_i
]

拉回：

[
m_i.
]

文献里也是这么描述的：ModUp 会把底层 plaintext polynomial 变成 (m+q_0I)，EvalMod 通过近似 modular reduction function 去除这个 (q_0I) 项。

如果某个 slot 的 (I_i) 太大，超出了 EvalMod 多项式设计的区间：

[
|I_i|>K,
]

那么 EvalMod 近似的是错误区间，可能直接失败。因此很多论文把 bootstrapping failure probability 写成：

[
\boxed{
\kappa=\Pr[|I|_{\infty}>K].
}
]

Subring secret 论文的实验表格也明确把 failure probability 定义为：

[
\kappa=\Pr[|I|_\infty>K].
]

并报告不同参数下的 (\log \kappa)。

所以你的理论噪声分析至少要分成两块：

[
\boxed{
\text{range failure: } \Pr[|I|_\infty>K]
}
]

和：

[
\boxed{
\text{precision failure: } \Pr[|e_{\mathrm{out}}|*\infty>\varepsilon*{\mathrm{target}}].
}
]

---

# 2. 你的 factored 方法会不会“肯定成功”？

不会无条件成功。

它成功需要满足：

[
\boxed{
\text{每个 leaf 的 EvalMod 输入都落在它自己的近似区间内。}
}
]

并且：

[
\boxed{
\text{Split/Merge、leaf C2S、leaf EvalMod、leaf S2C 产生的总误差小于目标精度预算。}
}
]

所以正确说法是：

[
\boxed{
\Pr[\mathrm{fail}_{\mathrm{fac}}]\le \delta
}
]

而不是：

[
\Pr[\mathrm{fail}_{\mathrm{fac}}]=0.
]

如果你想要高保证，就设：

[
\delta\le 2^{-40},\quad 2^{-64},\quad 2^{-128}
]

之类。Subring secret 论文中特别强调低失败概率很重要，因为 bootstrapping failures 可能被利用来做 key recovery attack；他们也报告了 (<2^{-128}) 级别的 bootstrapping failure probability。

---

# 3. 理论噪声分析的总体形式

你的 factored bootstrapping 可以写成：

[
\widetilde{\BTS}_{N,k}^{\mathrm{fac}}
=====================================

\gamma_{\mathrm{impl}}^{-1}
\Merge_k
\circ
\left(
\bigoplus_{r=0}^{k-1}
\StwoC_n
\circ
\EvalMod_n
\circ
\CtwoS_n
\right)
\circ
\Split_k
\circ
\ModUp_N
\circ
\ScaleDown_N.
]

其中：

[
n=N/k.
]

我们希望证明：

[
\widetilde{\BTS}_{N,k}^{\mathrm{fac}}(\ct)
==========================================

\BTS_N^{\mathrm{ideal}}(\ct)+e_{\mathrm{fac}},
]

并给出：

[
\Pr[|e_{\mathrm{fac}}|_\infty>\varepsilon]
\le
\delta.
]

---

# 4. 每一步的噪声上界

下面给你一个可以写进论文的理论框架。

---

## 4.1 输入噪声

设输入 ciphertext 解密后是：

[
m+e_0.
]

假设：

[
|e_0|_\infty\le B_0
]

以概率至少：

[
1-\delta_0.
]

如果 (e_0) 来自离散高斯或 subgaussian noise，可以用标准 tail bound：

[
\Pr[|e_0|_\infty>B_0]
\le
2N\exp\left(-\frac{B_0^2}{2\sigma_0^2}\right).
]

所以给定目标 (\delta_0)，可以取：

[
B_0
===

\sigma_0
\sqrt{2\log\frac{2N}{\delta_0}}.
]

---

## 4.2 ScaleDown / Rescale 噪声

ScaleDown / Rescale 本质上包含 rounding。可以写成：

[
e_1
===

\alpha_{\mathrm{SD}}e_0+\rho_{\mathrm{SD}}.
]

其中 (\rho_{\mathrm{SD}}) 是 rounding error。

给一个保守上界：

[
|\rho_{\mathrm{SD}}|*\infty\le B*{\mathrm{SD}}.
]

于是：

[
|e_1|*\infty
\le
|\alpha*{\mathrm{SD}}|B_0+B_{\mathrm{SD}}.
]

---

## 4.3 ModUp 后的 (I) 项

ModUp 后 plaintext 变成：

[
m+q_0I+e_1.
]

这里 (I) 是 EvalMod 要去掉的 integer wrap-around vector。

成功条件之一是：

[
\boxed{
|I|_\infty\le K.
}
]

所以：

[
\Pr[\mathrm{EvalMod\ range\ fail}]
==================================

\Pr[|I|_\infty>K].
]

在很多 CKKS bootstrapping 分析里，(K) 和 secret Hamming weight / secret norm 相关。Subring secret 论文说，EvalMod 需要在 (x\in[-K,K]) 上近似 (x\bmod1)，并且在他们的 subring secret 设置中有 (K=O(\sqrt h))，其中 (h) 是 secret Hamming weight。

因此你可以写：

[
K_{\mathrm{leaf}}
=================

c\sqrt{h_{\mathrm{leaf}}}
]

或者更保守地通过 estimator / distribution simulation 给出 (K_{\mathrm{leaf}})。

---

## 4.4 Split 噪声

如果 Split 只是 coefficients rearrangement，那么：

[
B_{\Split}=0.
]

HERMES 明确说，在 coefficients-encoded CKKS 中，Split/Combine 的 bijection 是 direct sum，也就是 coefficient rearrangement，几乎没有计算成本。

如果你的实现中 Split 伴随 key switching，则要加 key switching 噪声：

[
B_{\Split}=B_{\mathrm{KS,split}}.
]

因此每个 leaf 输入噪声满足：

[
B_{2,r}
\le
B_1+B_{\Split}.
]

---

## 4.5 Key switching 噪声

HERMES 把 key switching 写成：

[
\mathrm{KS}(ct;\mathrm{swk})
============================

\mathrm{ModDown}
\left(
\mathrm{MultSwk}(\mathrm{ModUp}(a),\mathrm{swk})
\right)
+
(b,0).
]

switching key 形如：

[
\mathrm{swk}=(-\hat a s' + ps+\hat e,\hat a)\in R_{qp,N}^2,
]

其中 (\hat e) 是小噪声。HERMES 也指出这个 switching key 可以把 (s) 下的 ciphertext 转成 (s') 下的 ciphertext，明文保持相同 up to small error。

理论上可以给每次 KS 一个 bound：

[
|e_{\mathrm{KS}}|*\infty
\le
B*{\mathrm{KS}}
]

with probability (1-\delta_{\mathrm{KS}})。

如果共有 (M_{\mathrm{KS}}) 次 key switching，用 union bound：

[
\Pr[\exists\ \mathrm{KS\ fails}]
\le
M_{\mathrm{KS}}\delta_{\mathrm{KS}}.
]

所以 key switching 贡献的总失败概率：

[
\boxed{
\delta_{\mathrm{KS,total}}
\le
M_{\mathrm{KS}}\delta_{\mathrm{KS}}.
}
]

总噪声可以保守相加：

[
B_{\mathrm{KS,total}}
\le
M_{\mathrm{KS}}B_{\mathrm{KS}}.
]

如果用均方或 subgaussian 组合，可以更紧：

[
B_{\mathrm{KS,total}}
\approx
\sqrt{M_{\mathrm{KS}}}B_{\mathrm{KS}},
]

但论文里保守安全通常先用线性上界。

---

## 4.6 C2S 噪声

C2S 是线性变换。设它的算子范数上界为：

[
|A_{\CtwoS,n}|*{\infty\to\infty}\le L*{\CtwoS,n}.
]

它内部还有 rotations / key switching / rescale noise，记为：

[
B_{\CtwoS,\mathrm{arith}}.
]

那么 leaf C2S 后噪声：

[
B_3
\le
L_{\CtwoS,n}B_2
+
B_{\CtwoS,\mathrm{arith}}.
]

其中：

[
B_{\CtwoS,\mathrm{arith}}
]

可以进一步分解为：

[
B_{\CtwoS,\mathrm{arith}}
=========================

M_{\CtwoS,\mathrm{KS}}B_{\mathrm{KS}}
+
B_{\CtwoS,\mathrm{round}}
+
B_{\CtwoS,\mathrm{rescale}}.
]

---

## 4.7 EvalMod 近似误差和失败概率

EvalMod 是关键。

设真实 modular reduction 函数为：

[
f(x)=x\bmod 1.
]

实现中用多项式：

[
p_d(x)
]

近似它。定义近似误差：

[
\epsilon_{\mathrm{poly}}
========================

\sup_{x\in[-K,K]}
|p_d(x)-f(x)|.
]

如果输入扰动是 (\delta x)，且 (p_d) 在区间上 Lipschitz 常数为：

[
L_{\mathrm{Eval}}
=================

\sup_{x\in[-K,K]} |p_d'(x)|,
]

则：

[
|p_d(x+\delta x)-f(x)|
\le
L_{\mathrm{Eval}}|\delta x|
+
\epsilon_{\mathrm{poly}}
+
B_{\Eval,\mathrm{arith}}.
]

因此 leaf EvalMod 后噪声上界：

[
\boxed{
B_4
\le
L_{\mathrm{Eval}}B_3
+
\epsilon_{\mathrm{poly}}
+
B_{\Eval,\mathrm{arith}}.
}
]

而 EvalMod range failure 是：

[
\boxed{
\delta_{\mathrm{range}}
=======================

\Pr[|I|_\infty>K].
}
]

Subring secret 论文中也明确说，EvalMod 要近似 (x\bmod1) 或 cosine/sine/exponential 等函数，并且 approximation polynomial degree 要随 (K) 增大而增大；它还指出理论上决定达到某个 precision 所需的 polynomial degree 和 double-angle 次数很困难。

所以这里最严谨的写法是：

[
\boxed{
\text{EvalMod error bound depends on } K,d,r,\epsilon_{\mathrm{poly}},L_{\mathrm{Eval}}.
}
]

---

## 4.8 S2C 噪声

S2C 也是线性变换。设：

[
|A_{\StwoC,n}|*{\infty\to\infty}\le L*{\StwoC,n}.
]

内部 arithmetic noise 是：

[
B_{\StwoC,\mathrm{arith}}.
]

则：

[
B_5
\le
L_{\StwoC,n}B_4
+
B_{\StwoC,\mathrm{arith}}.
]

---

## 4.9 Merge 噪声

如果 Merge 只是 coefficient rearrangement：

[
B_{\Merge}=0.
]

如果 Merge 伴随 key switching：

[
B_{\Merge}=B_{\mathrm{KS,merge}}.
]

考虑 implementation normalization：

[
\gamma_{\mathrm{impl}}^{-1}.
]

最终噪声：

[
\boxed{
B_{\mathrm{fac}}
\le
|\gamma_{\mathrm{impl}}|^{-1}
\left(
L_{\Merge}B_5+B_{\Merge}
\right).
}
]

如果 Merge 是 direct sum rearrangement：

[
L_{\Merge}\approx1.
]

所以：

[
\boxed{
B_{\mathrm{fac}}
\le
|\gamma_{\mathrm{impl}}|^{-1}
\left(
B_5+B_{\Merge}
\right).
}
]

---

# 5. 总的失败概率上界

失败事件可以分成：

[
\mathsf{Fail}_{\mathrm{fac}}
============================

\mathsf{Fail}*{\mathrm{range}}
\cup
\mathsf{Fail}*{\mathrm{KS}}
\cup
\mathsf{Fail}*{\mathrm{arith}}
\cup
\mathsf{Fail}*{\mathrm{precision}}.
]

用 union bound：

[
\boxed{
\Pr[\mathsf{Fail}*{\mathrm{fac}}]
\le
\delta*{\mathrm{range}}
+
\delta_{\mathrm{KS}}
+
\delta_{\mathrm{arith}}
+
\delta_{\mathrm{precision}}.
}
]

更具体地，对 (k) 个 leaves：

[
\delta_{\mathrm{range,fac}}
===========================

\Pr\left[
\max_{0\le r<k}|I_r|*\infty>K*{\mathrm{leaf}}
\right].
]

如果只用 union bound：

[
\boxed{
\delta_{\mathrm{range,fac}}
\le
\sum_{r=0}^{k-1}
\Pr[|I_r|*\infty>K*{\mathrm{leaf}}]
===================================

k\delta_{\mathrm{range,leaf}}.
}
]

如果假设 leaves 独立，则可以写成近似：

[
\delta_{\mathrm{range,fac}}
===========================

1-(1-\delta_{\mathrm{range,leaf}})^k
\approx
k\delta_{\mathrm{range,leaf}}.
]

但严谨起见不要假设独立，直接用 union bound：

[
\boxed{
\delta_{\mathrm{range,fac}}
\le
k\delta_{\mathrm{range,leaf}}.
}
]

如果目标是：

[
\delta_{\mathrm{fac}}\le 2^{-128},
]

那么你需要让：

[
\delta_{\mathrm{range,leaf}}
\le
\frac{2^{-128}}{k}
]

并且给 KS 和 arithmetic failure 留预算。

---

# 6. “肯定成功”什么时候可以说？

只有在非常强的 deterministic bound 下才能说。

例如你能证明：

[
|I_r|*\infty\le K*{\mathrm{leaf}}
\quad
\text{for all possible inputs and randomness}
]

并且：

[
B_{\mathrm{fac}}\le \varepsilon_{\mathrm{target}}
]

对所有随机噪声都成立。

但 RLWE/CKKS 里的 encryption noise、key switching noise 通常是高斯或近似高斯采样，理论上有无限尾部。离散高斯没有绝对有限上界，所以不能说概率 (1) 成功。

实际论文通常说：

[
\boxed{
\text{failure probability is at most } \delta.
}
]

而不是：

[
\boxed{
\text{failure probability is zero.}
}
]

---

# 7. 对你的方法，理论上最重要的新增风险是什么？

你的 no-(B_k) 方法相对 direct 增加了三类风险。

## 7.1 Leaf 数量导致 union bound 放大

direct 只需要一个 EvalMod range event：

[
|I|_\infty\le K.
]

factored 有 (k) 个 leaves：

[
|I_0|*\infty\le K*{\mathrm{leaf}},\ldots,|I_{k-1}|*\infty\le K*{\mathrm{leaf}}.
]

所以：

[
\delta_{\mathrm{range,fac}}
\le
k\delta_{\mathrm{range,leaf}}.
]

这通常不是大问题。如果你把 leaf failure 做到：

[
2^{-140}
]

而 (k=2) 或 (4)，整体仍然非常小。

---

## 7.2 Split/Merge key switching 噪声

如果 Split/Merge 不是纯 rearrangement，而是涉及 ring/key switching，则每次都加：

[
B_{\mathrm{KS}}.
]

如果 Split/Merge key switching 次数是：

[
M_{\mathrm{SM}},
]

则：

[
B_{\mathrm{SM}}
\le
M_{\mathrm{SM}}B_{\mathrm{KS}}
]

保守上界。

对应失败概率：

[
\delta_{\mathrm{SM}}
\le
M_{\mathrm{SM}}\delta_{\mathrm{KS}}.
]

---

## 7.3 Leaf EvalMod 参数必须重新选

leaf degree 是：

[
n=N/k.
]

leaf secret、leaf noise、leaf (I_r) 分布可能和 top direct 不同。不能直接拿 top 的 (K)、degree (d)、double-angle (r) 不分析就用。

你需要为 leaf 单独选择：

[
K_{\mathrm{leaf}},
\quad
d_{\mathrm{leaf}},
\quad
r_{\mathrm{leaf}},
\quad
\Delta_{\mathrm{leaf}},
\quad
Q_{\mathrm{leaf}}.
]

满足：

[
\Pr[|I_r|*\infty>K*{\mathrm{leaf}}]
\le
\delta_{\mathrm{range,leaf}},
]

以及：

[
L_{\mathrm{Eval}}B_3+\epsilon_{\mathrm{poly}}+B_{\Eval,\mathrm{arith}}
\le
B_{\Eval,\mathrm{budget}}.
]

---

# 8. 可以写成一个正式 proposition

你可以在文档里这样写：

**Proposition.** Suppose that for every leaf (r), the following hold with probability at least (1-\delta_r):

[
|I_r|*\infty\le K*{\mathrm{leaf}},
]

[
|e_{\Split,r}|*\infty\le B*{\Split},
]

[
|e_{\CtwoS,r}|*\infty\le B*{\CtwoS},
]

[
|e_{\EvalMod,r}|*\infty\le
L*{\Eval}B_{\CtwoS}
+
\epsilon_{\mathrm{poly}}
+
B_{\Eval,\mathrm{arith}},
]

[
|e_{\StwoC,r}|*\infty\le B*{\StwoC},
]

and the merge error is bounded by (B_{\Merge}). Then the normalized factored bootstrapping output satisfies

[
|\Dec(\widetilde{\BTS}*{N,k}^{\mathrm{fac}}(\ct))-m|*\infty
\le
|\gamma_{\mathrm{impl}}|^{-1}
\left(
L_{\Merge}
\left[
L_{\StwoC}
\left(
L_{\Eval}L_{\CtwoS}(B_0+B_{\Split})
+
L_{\Eval}B_{\CtwoS,\mathrm{arith}}
+
\epsilon_{\mathrm{poly}}
+
B_{\Eval,\mathrm{arith}}
\right)
+
B_{\StwoC,\mathrm{arith}}
\right]
+
B_{\Merge}
\right)
]

with probability at least

[
1-
\left(
k\delta_{\mathrm{range,leaf}}
+
M_{\mathrm{KS}}\delta_{\mathrm{KS}}
+
\delta_{\mathrm{poly}}
+
\delta_{\mathrm{round}}
\right).
]

这个式子很丑，但它就是理论噪声界的正确形态。

# 9. 结论：能不能分析？能。但不要声称“必然成功”

最准确的结论是：

[
\boxed{
\text{可以给出理论上界：噪声增长上界 + failure probability 上界。}
}
]

但：

[
\boxed{
\text{不能无条件说一定成功。}
}
]

因为失败概率来自：

1. 离散高斯 / RLWE noise 的尾部；
2. key switching noise 的尾部；
3. ModDown / Rescale rounding；
4. EvalMod 输入 (I) 超出 ([-K,K])；
5. EvalMod polynomial approximation error；
6. CKKS 最终 precision budget 不足。

对你的方法，最终应该写：

[
\boxed{
\Pr[\mathrm{fail}*{\mathrm{fac}}]
\le
k\Pr[|I*{\mathrm{leaf}}|*\infty>K*{\mathrm{leaf}}]
+
M_{\mathrm{KS}}\delta_{\mathrm{KS}}
+
\delta_{\mathrm{arith}}
+
\delta_{\mathrm{precision}}.
}
]

如果你把每一项都设到足够小，比如总和小于：

[
2^{-64}
\quad\text{或}\quad
2^{-128},
]

就可以声称：

[
\boxed{
\text{correctness holds except with negligible probability.}
}
]

这就是理论噪声/失败概率分析的标准写法。
