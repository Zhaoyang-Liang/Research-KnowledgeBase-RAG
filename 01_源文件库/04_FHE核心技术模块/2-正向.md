可以。下面我只写**一个方向**，而且写成**在 CKKS 密文上确实能算通**的版本：

> **输入**：一个密文，它加密的是
> [
> P(Y)=\sum_{j=0}^{2n-1}p_jY^j
> ]
> 的 CKKS 明文。
> **输出**：两个密文，分别加密 FFT 奇偶分解中的
> [
> P_{\mathrm{even}}(T)=\sum_{i=0}^{n-1}p_{2i}T^i,
> \qquad
> P_{\mathrm{odd}}(T)=\sum_{i=0}^{n-1}p_{2i+1}T^i.
> ]

我选这个版本，而**不**选你前面说的直接用 (E,O) 作用在 ((p_0,\dots,p_{2n-1})) 上的版本，原因是：

* 这个版本**直接在多项式密文上做**，不需要先 CoeffToSlot；
* 每一步都是 CKKS 里标准可做的：

  * Galois automorphism（自同构）
  * 加法/减法
  * 明文-密文乘法

所以这是**更适合、也更正确**的版本。

---

# 0. 目标与设定

设
[
P(Y)=\sum_{j=0}^{2n-1}p_jY^j \in \mathbb{R}[Y]/(Y^{2n}+1).
]

定义偶、奇部分多项式：

[
P_{\mathrm{even}}(T)=\sum_{i=0}^{n-1}p_{2i}T^i,
]
[
P_{\mathrm{odd}}(T)=\sum_{i=0}^{n-1}p_{2i+1}T^i.
]

于是有标准 FFT 递归分解：

[
P(Y)=P_{\mathrm{even}}(Y^2)+Y,P_{\mathrm{odd}}(Y^2). \tag{1}
]

---

## 嵌入到 CKKS 的实际密文环

CKKS 实际工作在
[
R_N=\mathbb{Z}[X]/(X^N+1),
]
其中 (N) 是 2 的幂。

令
[
k=\frac{N}{2n},
\qquad Y=X^k.
]

于是
[
Y^{2n}=X^{2nk}=X^N=-1,
]
所以 (Y) 的确满足
[
Y^{2n}+1=0.
]

因此，(P(Y)) 在实际密文环里对应为

[
P(X^k)=\sum_{j=0}^{2n-1}p_jX^{jk}. \tag{2}
]

---

## 输入密文

设输入密文为

[
\mathbf{ct}_P=\operatorname{Enc}(m_P(X)),
]

其中
[
m_P(X)\approx \left\lfloor \Delta\cdot P(X^k)\right\rfloor. \tag{3}
]

这里 (\Delta) 是 CKKS 的 scale。
“(\approx)” 表示 usual CKKS 语义：包含编码舍入误差和加密误差。

---

# 1. 第一步：构造 (P(-Y)) 的密文

我们要先得到一个密文，对应于
[
P(-Y)=P(-X^k).
]

这一步用一个 **Galois automorphism** 完成。

---

## 1.1 选取自同构指数

在 (R_N) 中，任意奇数 (a) 对应一个环自同构
[
\sigma_a:R_N\to R_N,\qquad f(X)\mapsto f(X^a).
]

我们取
[
a=1+2n.
]

因为 (2n) 是偶数，所以 (1+2n) 是奇数，故 (\sigma_{1+2n}) 是合法的 CKKS 自同构。

---

## 1.2 检查它对 (Y=X^k) 的作用

由于 (k=N/(2n))，所以
[
2nk=N.
]

于是
[
\sigma_{1+2n}(Y)
================

# \sigma_{1+2n}(X^k)

# X^{k(1+2n)}

# X^{k+2nk}

X^{k+N}.
]

又因为在 (R_N) 中
[
X^N=-1,
]
所以
[
X^{k+N}=X^N X^k = -X^k.
]

因此
[
\sigma_{1+2n}(Y)=-Y. \tag{4}
]

---

## 1.3 对输入密文应用该自同构

定义
[
\mathbf{ct}*{-}:=\sigma*{1+2n}(\mathbf{ct}_P).
]

则其明文语义为
[
\mathbf{ct}_{-}
===============

\operatorname{Enc}(m_{-}(X)),
]
其中
[
m_{-}(X)\approx \left\lfloor \Delta\cdot P(-X^k)\right\rfloor. \tag{5}
]

也就是
[
\mathbf{ct}_{-}
]
是 (P(-Y)) 的密文。

---

# 2. 第二步：由 (P(Y)) 和 (P(-Y)) 取出偶部分

根据 (1)，我们有

[
P(Y)=P_{\mathrm{even}}(Y^2)+Y,P_{\mathrm{odd}}(Y^2),
]
[
P(-Y)=P_{\mathrm{even}}(Y^2)-Y,P_{\mathrm{odd}}(Y^2).
]

两式相加得到

[
P(Y)+P(-Y)=2P_{\mathrm{even}}(Y^2). \tag{6}
]

所以

[
P_{\mathrm{even}}(Y^2)=\frac{P(Y)+P(-Y)}{2}. \tag{7}
]

---

## 2.1 在密文上执行这一步

定义
[
\mathbf{ct}_{\mathrm{even}}^{\uparrow}
:=
\operatorname{Ecd}!\left(\frac12\right)\times
\bigl(\mathbf{ct}*P+\mathbf{ct}*{-}\bigr). \tag{8}
]

这里 (\operatorname{Ecd}(1/2)) 是明文常数 (1/2) 的编码。

---

## 2.2 输出密文的语义

由 (6)(7) 得

[
\mathbf{ct}_{\mathrm{even}}^{\uparrow}
======================================

\operatorname{Enc}(m_{\mathrm{even}}^{\uparrow}(X)),
]
其中
[
m_{\mathrm{even}}^{\uparrow}(X)
\approx
\left\lfloor
\Delta\cdot P_{\mathrm{even}}(X^{2k})
\right\rfloor. \tag{9}
]

因为
[
Y^2=(X^k)^2=X^{2k}.
]

把 (P_{\mathrm{even}}) 展开写出来就是

[
P_{\mathrm{even}}(X^{2k})
=========================

\sum_{i=0}^{n-1}p_{2i}X^{2ik}. \tag{10}
]

所以
[
\mathbf{ct}_{\mathrm{even}}^{\uparrow}
]
对应的是“偶数系数那一支”的密文。

这里上标 ({}^{\uparrow}) 的意思是：

> 它还留在原来的大环 (R_N) 里，只不过它的明文只含 (X^{2k}) 的幂，因此实际上已经落在更小的子环里了。

---

# 3. 第三步：由 (P(Y)) 和 (P(-Y)) 取出奇部分（带一个 (Y) 因子）

同理，由两式相减得到

[
P(Y)-P(-Y)=2Y,P_{\mathrm{odd}}(Y^2). \tag{11}
]

所以

[
Y,P_{\mathrm{odd}}(Y^2)=\frac{P(Y)-P(-Y)}{2}. \tag{12}
]

---

## 3.1 在密文上执行这一步

定义
[
\mathbf{ct}_{\mathrm{odd},Y}^{\uparrow}
:=
\operatorname{Ecd}!\left(\frac12\right)\times
\bigl(\mathbf{ct}*P-\mathbf{ct}*{-}\bigr). \tag{13}
]

---

## 3.2 输出密文的语义

由 (11)(12) 得

[
\mathbf{ct}_{\mathrm{odd},Y}^{\uparrow}
=======================================

\operatorname{Enc}(m_{\mathrm{odd},Y}^{\uparrow}(X)),
]
其中
[
m_{\mathrm{odd},Y}^{\uparrow}(X)
\approx
\left\lfloor
\Delta\cdot X^k,P_{\mathrm{odd}}(X^{2k})
\right\rfloor. \tag{14}
]

因为
[
Y=X^k.
]

把 (P_{\mathrm{odd}}) 展开写出来就是

[
X^kP_{\mathrm{odd}}(X^{2k})
===========================

\sum_{i=0}^{n-1}p_{2i+1}X^{(2i+1)k}. \tag{15}
]

所以
[
\mathbf{ct}_{\mathrm{odd},Y}^{\uparrow}
]
对应的是“奇数系数那一支”，但**前面多了一个 (Y=X^k) 因子**。

---

# 4. 第四步（可选）：去掉奇部分前面的 (Y)

很多时候为了继续做 FFT 递归，我们更希望得到的是

[
P_{\mathrm{odd}}(Y^2)
]
而不是
[
Y,P_{\mathrm{odd}}(Y^2).
]

这一步也可以同态完成。

---

## 4.1 先求 (Y^{-1})

因为
[
Y=X^k,
]
而在 (R_N) 中
[
X^N=-1,
]
所以
[
X^k\cdot(-X^{N-k})=-X^N=1.
]

因此
[
Y^{-1}=-X^{N-k}. \tag{16}
]

---

## 4.2 用明文-密文乘法去掉 (Y)

定义明文单项式
[
\mu_{\mathrm{odd}}(X):=-X^{N-k}. \tag{17}
]

然后计算
[
\mathbf{ct}*{\mathrm{odd}}^{\uparrow}
:=
\operatorname{Ecd}(\mu*{\mathrm{odd}}(X))
\times
\mathbf{ct}_{\mathrm{odd},Y}^{\uparrow}. \tag{18}
]

---

## 4.3 输出密文的语义

由 (16) 可知

[
\mu_{\mathrm{odd}}(X)\cdot X^k = 1.
]

因此

[
\mathbf{ct}_{\mathrm{odd}}^{\uparrow}
=====================================

\operatorname{Enc}(m_{\mathrm{odd}}^{\uparrow}(X)),
]
其中
[
m_{\mathrm{odd}}^{\uparrow}(X)
\approx
\left\lfloor
\Delta\cdot P_{\mathrm{odd}}(X^{2k})
\right\rfloor. \tag{19}
]

展开写即

[
P_{\mathrm{odd}}(X^{2k})
========================

\sum_{i=0}^{n-1}p_{2i+1}X^{2ik}. \tag{20}
]

这样，我们就真正得到了“偶分支”和“奇分支”两个同形的密文。

---

# 5. 到这里，输出是什么

最终我们有两种可选输出形式。

---

## 形式 A：不去掉 (Y) 因子

输出为

[
\mathbf{ct}*{\mathrm{even}}^{\uparrow}
\quad\text{和}\quad
\mathbf{ct}*{\mathrm{odd},Y}^{\uparrow}.
]

它们分别加密

[
P_{\mathrm{even}}(X^{2k}),
\qquad
X^kP_{\mathrm{odd}}(X^{2k}).
]

优点：

* 不需要最后一步明文-密文乘法；
* 少耗一个 level。

缺点：

* 奇支和偶支的形式不完全对称。

---

## 形式 B：去掉 (Y) 因子

输出为

[
\mathbf{ct}*{\mathrm{even}}^{\uparrow}
\quad\text{和}\quad
\mathbf{ct}*{\mathrm{odd}}^{\uparrow}.
]

它们分别加密

[
P_{\mathrm{even}}(X^{2k}),
\qquad
P_{\mathrm{odd}}(X^{2k}).
]

优点：

* 两个输出完全对称；
* 最适合继续递归做 FFT / NTT 式分解。

缺点：

* 多做一次明文-密文乘法，通常多耗 1 个 level。

---

# 6. 这件事为什么是“真正在密文上算通”的

上面每一步都对应 CKKS 里标准支持的操作：

1. **Galois automorphism**
   [
   \mathbf{ct}*P \mapsto \mathbf{ct}*{-}
   ]
   需要相应的 automorphism key（也可叫 rotation / Galois key）。

2. **加法 / 减法**
   [
   \mathbf{ct}*P \pm \mathbf{ct}*{-}
   ]

3. **明文常数乘法**
   [
   \operatorname{Ecd}(1/2)\times(\cdot)
   ]

4. **可选：明文单项式乘法**
   [
   \operatorname{Ecd}(-X^{N-k})\times(\cdot)
   ]

因此这不是“抽象上存在”，而是**确实能作为同态电路执行**。

---

# 7. 与 FFT 奇偶系数向量的对应关系

注意：

[
P_{\mathrm{even}}(T)=\sum_{i=0}^{n-1}p_{2i}T^i
]
的系数向量正是
[
(p_0,p_2,\dots,p_{2n-2}),
]

[
P_{\mathrm{odd}}(T)=\sum_{i=0}^{n-1}p_{2i+1}T^i
]
的系数向量正是
[
(p_1,p_3,\dots,p_{2n-1}).
]

所以，这两个输出密文**正对应**你要的 FFT 奇偶分拆。

只是它们现在仍然是“多项式密文”，而不是“槽里直接装了这两个向量的密文”。

如果你后面还想把它们变成两个“槽向量密文”，那就在这一步之后再分别做一次较小维度的 CoeffToSlot。

---

# 8. 把整个正向过程压成一条公式链

设
[
P(Y)=\sum_{j=0}^{2n-1}p_jY^j,
\qquad
P_{\mathrm{even}}(T)=\sum_{i=0}^{n-1}p_{2i}T^i,
\qquad
P_{\mathrm{odd}}(T)=\sum_{i=0}^{n-1}p_{2i+1}T^i,
]
[
Y=X^k,\qquad k=\frac{N}{2n}.
]

输入：
[
\mathbf{ct}_P=\operatorname{Enc}!\left(\left\lfloor \Delta P(X^k)\right\rfloor\right).
]

先做自同构：
[
\mathbf{ct}*{-}=\sigma*{1+2n}(\mathbf{ct}*P),
\qquad
\sigma*{1+2n}(X^k)=-X^k.
]

得到
[
\mathbf{ct}_{-}
===============

\operatorname{Enc}!\left(\left\lfloor \Delta P(-X^k)\right\rfloor\right).
]

再做偶支：
[
\mathbf{ct}_{\mathrm{even}}^{\uparrow}
======================================

\operatorname{Ecd}!\left(\frac12\right)\times
\bigl(\mathbf{ct}*P+\mathbf{ct}*{-}\bigr)
=========================================

\operatorname{Enc}!\left(
\left\lfloor \Delta P_{\mathrm{even}}(X^{2k})\right\rfloor
\right).
]

再做奇支（带 (Y)）：
[
\mathbf{ct}_{\mathrm{odd},Y}^{\uparrow}
=======================================

\operatorname{Ecd}!\left(\frac12\right)\times
\bigl(\mathbf{ct}*P-\mathbf{ct}*{-}\bigr)
=========================================

\operatorname{Enc}!\left(
\left\lfloor \Delta X^kP_{\mathrm{odd}}(X^{2k})\right\rfloor
\right).
]

可选地去掉 (Y)：
[
\mathbf{ct}_{\mathrm{odd}}^{\uparrow}
=====================================

# \operatorname{Ecd}(-X^{N-k})\times \mathbf{ct}_{\mathrm{odd},Y}^{\uparrow}

\operatorname{Enc}!\left(
\left\lfloor \Delta P_{\mathrm{odd}}(X^{2k})\right\rfloor
\right).
]

---

# 9. 最后一句结论

所以，**把一个加密 (P(Y)) 的 CKKS 密文，按 FFT 的奇偶方式拆成两个密文，是可以在密文上严格完成的**。
而且最合适的做法不是直接拿 (E,O) 去抽系数向量，而是利用

[
P(Y)=P_{\mathrm{even}}(Y^2)+Y P_{\mathrm{odd}}(Y^2),
\qquad
P(-Y)=P_{\mathrm{even}}(Y^2)-Y P_{\mathrm{odd}}(Y^2)
]

这组恒等式，在密文上通过**自同构 + 加减 + 明文乘法**来实现。

你要是愿意，我下一条就继续把**反方向**也按同样严谨程度写出来：
从
[
\mathbf{ct}*{\mathrm{even}}^{\uparrow},\ \mathbf{ct}*{\mathrm{odd}}^{\uparrow}
]
或者
[
\mathbf{ct}*{\mathrm{even}}^{\uparrow},\ \mathbf{ct}*{\mathrm{odd},Y}^{\uparrow}
]
合成回 (\mathbf{ct}_P)。
