# 最核心的一句话先说出来

对分圆多项式 (\Phi_m(X)) 来说，**所有不可约因子的次数都相同**，根本原因是：

> 在有限域上，不可约因子的次数 = Frobenius 自同构轨道的长度；
> 而对 (\Phi_m) 的所有根来说，这些轨道长度都一样，且都等于

下面我把这句话慢慢拆开。

---

# 1. 从抽象代数开始：在有限域上，不可约因子的次数是什么？

我们先不看分圆多项式，先看一般情形。

设底域是 (\mathbb F_q)，这里最终我们要取 (q=2)。
设 (f(X)\in \mathbb F_q[X])，我们把它放到某个分裂域里去看根。

令 (\alpha) 是 (f) 的一个根。
那么 (\alpha) 在 (\mathbb F_q) 上的最小多项式 (m_\alpha(X)) 的次数，就是：

[
[\mathbb F_q(\alpha):\mathbb F_q].
]

这就是抽象代数里“一个根所在不可约因子的次数”。

---

## 为什么它和 Frobenius 有关？

在有限域里，有一个最重要的自同构：

[
\mathrm{Frob}_q:x\mapsto x^q.
]

在我们这里 (q=2)，所以就是

[
\mathrm{Frob}:x\mapsto x^2.
]

它有一个经典事实：

> (\alpha) 在 (\mathbb F_q) 上的共轭元正好是
> [
> \alpha,\alpha^q,\alpha^{q^2},\dots
> ]
> 直到第一次回到 (\alpha) 为止。

所以最小多项式的次数，等于 Frobenius 轨道长度：

[
\deg m_\alpha
=============

\min{d>0:\alpha^{q^d}=\alpha}.
]

对 (q=2)，这变成：

[
\deg m_\alpha
=============

\min{d>0:\alpha^{2^d}=\alpha}.
]

这一步是最关键的桥梁：

> **不可约因子的次数 = 根在 Frobenius 作用下的轨道长度。**

---

# 2. 现在专门看分圆多项式 (\Phi_m(X))

设 (m) 是奇数。
(\Phi_m(X)) 的根是什么？

它的根是所有**本原 (m) 次单位根**，也就是那些满足：

[
\zeta^m=1
]

并且 (\zeta) 的阶正好是 (m) 的元素。

如果 (\zeta) 是一个本原 (m) 次单位根，那么所有根都写成

[
\zeta^a,\qquad a\in (\mathbb Z/m\mathbb Z)^\times.
]

因为只有当 (\gcd(a,m)=1) 时，(\zeta^a) 仍然是本原的。

所以 (\Phi_m) 的所有根构成一个集合：

[
{\zeta^a : a\in(\mathbb Z/m\mathbb Z)^\times},
]

这个集合有 (\varphi(m)) 个元素，也就是

[
\deg \Phi_m = \varphi(m)=N.
]

这和论文写的 (N=\varphi(m)) 一致。

---

# 3. Frobenius 在这些根上怎么作用？

因为我们现在是在特征 2 里，所以 Frobenius 是

[
x\mapsto x^2.
]

于是对一个根 (\zeta^a)，它的像就是

[
(\zeta^a)^2=\zeta^{2a}.
]

再作用一次：

[
(\zeta^a)^{2^2}=\zeta^{2^2 a}.
]

再作用 (k) 次：

[
(\zeta^a)^{2^k}=\zeta^{2^k a}.
]

所以 Frobenius 在根集合上的作用，本质上就是：

[
a\mapsto 2a \pmod m.
]

这已经很接近答案了。

---

# 4. 一个根的轨道长度为什么等于最小的 (d) 使 (2^d\equiv 1\pmod m)？

取一个根 (\zeta^a)，其中 (\gcd(a,m)=1)。

我们要找它的 Frobenius 轨道长度，也就是最小的 (d>0) 使得：

[
(\zeta^a)^{2^d}=\zeta^a.
]

这等价于：

[
\zeta^{a2^d}=\zeta^a.
]

移到一边：

[
\zeta^{a(2^d-1)}=1.
]

因为 (\zeta) 的阶是 (m)，所以这等价于

[
m \mid a(2^d-1).
]

而 (\gcd(a,m)=1)，所以 (a) 在模 (m) 下可逆，于是进一步等价于：

[
m\mid (2^d-1),
]

也就是

[
2^d\equiv 1\pmod m.
]

因此，轨道长度正好是满足这个条件的最小正整数：

[
d=\operatorname{ord}_m(2).
]

这就解释了为什么论文说：

> “This degree (d) is the smallest integer such that (2^d\equiv 1\pmod m).” 

---

# 5. 为什么所有不可约因子的次数都一样？

现在最关键的一步来了。

你可能会问：

> 上面只是对某一个根 (\zeta^a) 算出了轨道长度，为什么所有根都一样？

答案就在刚才那个推导里。

我们对 (\zeta^a) 的轨道长度求出来时，最后条件变成：

[
2^d\equiv 1\pmod m.
]

注意这里**已经没有 (a)** 了。

也就是说，只要 (\zeta^a) 还是本原 (m) 次根（也就是 (\gcd(a,m)=1)），它的轨道长度都由同一个条件决定，因此每个本原根的轨道长度都一样，都是

[
d=\operatorname{ord}_m(2).
]

而每个不可约因子对应一条 Frobenius 轨道，所以：

* 每个不可约因子的次数都等于对应轨道长度；
* 每条轨道长度都一样，都是 (d)。

因此：

> **(\Phi_m(X)) 模 2 后的所有不可约因子，次数全都相等，而且都等于 (d=\operatorname{ord}_m(2))。**

这就是“为什么是 (d)”最本质的解释。

---

# 6. 那为什么因子个数是 (r=N/d)？

因为：

* 总共有 (N=\varphi(m)) 个根；
* 每个 Frobenius 轨道有 (d) 个根；
* 不同轨道对应不同不可约因子。

所以轨道个数，也就是不可约因子个数，是

[
r=\frac{N}{d}=\frac{\varphi(m)}{d}.
]

这也正是论文写的：

[
r=N/d,
\qquad d=N/r.
]



所以这里的 (d=N/r) 并不是“先凭空定义出来的神秘量”，而是：

1. 先由 Frobenius 轨道长度得到一个内在的 (d=\operatorname{ord}_m(2))；
2. 再因为总根数是 (N)，每轨道长度是 (d)，所以 (r=N/d)；
3. 于是自然也有 (d=N/r)。

如果你想要更纯粹的抽象代数表述，可以这样记：

## 在有限域 (\mathbb F_q) 上

一个可分多项式的不可约分解，由 Frobenius 自同构
[
x\mapsto x^q

在根集上的轨道分解决定。

* 每个轨道对应一个不可约因子；
* 轨道长度 = 该因子的次数。

[

]

于是轨道长度等于在群 ((\mathbb Z/m\mathbb Z)^\times) 中，元素 (2) 的乘法阶：

[
d=\operatorname{ord}_m(2).
]

所以所有轨道同长度 (d)，因此所有不可约因子的次数都等于 (d)。

# 11. 现在我再把刚才那句原话，用没有跳步的方式重写一遍

原来那句“编码前还差一步：先把 (K_n) 元素放进单个槽”，现在可以重写成：

> 由于总明文环 (A) 分裂成很多槽 (L_i)，而每个槽本质上是一个较大的有限域 (\mathbb F_{2^d})，所以如果 (n\mid d)，我们可以把想处理的小域 (K_n=\mathbb F_{2^n}) 嵌入每个槽中。为此，先把 (K_n) 表示成 (\mathbb F_2[T]/(K_n(T)))，记其根为 (\psi)；再在第 (i) 个槽 (L_i) 中找一个同样满足 (K_n(T)=0) 的元素 (\sigma_{n,i}(\theta_i))。于是小域中的元素 (\alpha(\psi)) 就可以通过代换 (\psi\mapsto \sigma_{n,i}(\theta_i)) 送入第 (i) 个槽，这个映射就是 (\Psi_{n,i})。

这就是那句话完整、不跳步的意思。
