> 批次: Batch-01 | 已读: 24 篇

## 依赖层级总图

```
L0: 抽象代数
  +-- 群 (Group)
  +-- 环 (Ring)
  +-- 域 (Field)
  +-- 多项式环 Z[X]/(f(X))

L1: 代数数论基础
  +-- 不可约多项式 (Eisenstein 判别法)
  +-- 分圆多项式 Phi_m(X)
  +-- 分圆域 Q(zeta_m)
  +-- Galois 群 Gal(Q(zeta_m)/Q) = (Z/mZ)^x
  +-- 迹 (Trace) 与范数 (Norm)
  +-- 扩张次数 [L:K] = phi(m)
  +-- 共轭元素与自同构

L2: 有限域与分圆分解
  +-- F_p 上的分圆多项式分解
  +-- d = ord_m(p) -> Frobenius 轨道
  +-- CRT -> 槽 (slot) 分割
  +-- 每个 slot = F_{p^d}
  +-- NTT = 有限域上的 DFT

L3: RLWE 与环构造
  +-- R = Z[X]/(X^N+1), N = 2^k
  +-- R_q = Z_q[X]/(X^N+1)
  +-- R_t = Z_t[X]/(X^N+1)
  +-- LWE / RLWE 困难假设
  +-- SVP / CVP 格困难问题

L4: FHE 基础方案
  +-- Gentry09 (理想格, SWHE + Bootstrapping)
  +-- BGV (低位消息 + ModSwitch)
  +-- BFV (高位消息 + Rescale)
  +-- CKKS (典范嵌入 + 近似计算)

L5: 核心同态技术
  +-- 密钥切换 / 重线性化 (数字分解)
  +-- 模数切换 vs 重缩放
  +-- 噪声管理与自举 (Bootstrapping)
  +-- SlotToCoeff / CoeffToSlot (NTT 分解)
  +-- Galois 自同构 -> 旋转 / 共轭

L6: 高级操作
  +-- Trace / Product 操作 (旋转复合)
  +-- 多项式代换 Y = X^{N/(2n)}
  +-- Coefficient split (偶奇分解)
  +-- Slot-preserving split
  +-- Blind rotation (PaCo)
  +-- Packing relation (打包关系)

L7: 当前论文构造
  +-- Field Switching (大环<->小环)
  +-- 塔式分圆扩张
  +-- 三步流程: 切换密钥 -> 映射 -> 恢复
  +-- 并行引导 (PaCo)
```
