## 核心参数谱系

```
                      m (分圆指标)

                      Phi_m(X) = X^{N} + 1 (当 m=2^(k+1) 时 N=2^k)

                  +---+---+
                  |        |
           N = phi(m)     q (密文模数)
           (环维度)     |
                  |     +-- 安全级别 lambda -> q 的比特长 log q
                  |     |
          R = Z[X]/Phi_m(X)   t (明文模数, BGV/BFV)
                  |          |
           R_q = Z_q[X]/Phi_m  +-- d = ord_m(t) -> slot 维度
                  |          +-- L = phi(m)/d  -> slot 数量
         p (CKKS 编码因子)  +-- BGV: ModSwitch 链 q_0,...,q_L
                  |          |    q_{ell} = q_0 * Delta^ell
         Delta (CKKS scale) +-- BFV: Delta = floor(q/t)
                  |               q 链 = q, q/t, q/t^2, ...
      CKKS: tau_n 嵌入          +-- CKKS: 无 t, 用 Delta 和编解码
         |
   complex embeddings -> Galois automorphisms
         |
   rotation steps -> Tr_{n->B}
```

| 参数 | 含义 | 公式/关系 | 来源 |

| N = phi(m) | 环维度 | N = 2^{k-1} (若 m = 2^k) | `01_源文件库/01_抽象代数与代数数论/为什么选择分圆多项式-好处汇总.md` |

| R_t | 明文环 | R_t = Z_t[X]/(X^N+1) | 同上 |

## B. 明文模数与 Slot (BGV/BFV)

| 参数 | 含义 | 公式 | 来源 |
|------|------|------|------|
| t (或 p) | 明文模数 | 素数幂 | `01_源文件库/01_抽象代数与代数数论/分圆多项式的F_p分解.md` |
| d | slot 维度 | d = ord_{2N}(t) = min{k: t^k = 1 (mod 2N)} | 同上 |
| L | slot 数量 | L = phi(2N)/d = N/d | 同上 |
| 每个 slot | 结构 | 当 t 为素数时 = F_{t^d} | 同上 |

特殊取值:
- d = 1 <-> t = 1 (mod 2N): slot 数最大 L = N, 每个 slot = F_t
- d = N <-> t 是模 2N 的原根: 只有 1 个 slot = F_{t^N}

## F. 噪声控制 (三种方案区别) 【需核原论文】

| 方案 | 噪声控制 | 关键参数 | 操作 |
|------|---------|---------|------|
| BGV | 模数切换 | q -> q' (任意比例) | c' = floor((q'/q) * c) |
| BFV | 重缩放 | q -> q/t (固定比例) | c' = floor((1/t) * c) (Delta恢复) |
| CKKS | 重缩放 | q -> q/Delta | c' = floor((1/Delta) * c) (scale恢复) |

**重要区分**:
- BGV ModSwitch: 缩小模数但不改变明文尺度 (src_000014)
- BFV Rescale: 同时缩小模数和明文缩放因子 (src_000014)
- CKKS Rescale: 同时缩小模数和编码精度因子 — 在PaCo论文中可能使用两个不同的缩放因子 p 和 Delta【需核原论文】 (src_000024)
