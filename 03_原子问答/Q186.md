# 什么是格的平行六面体泄漏攻击？

平行六面体泄漏（learning the parallelepiped）是 Nguyen-Regev 2006 攻击 GGH/NTRUSign 的方法。

攻击原理：(1) GGH 签名 s 恰好落在私钥基 B_sk 决定的平行六面体 P(B_sk) = {B_sk x : −1/2 ≤ x_i < 1/2} 内。(2) 接收多个 (m, s) 对 → s 值构成 P(B_sk) 内的均匀采样点。(3) 计算这些点的协方差矩阵，协方差矩阵的特征向量正好对应 B_sk 的 Gram-Schmidt 向量方向。(4) 通过 Gram-Schmidt 方向可以直接重构私钥基。

几何直觉：P(B_sk) 是一个歪斜的盒子，每个签名都是盒子里的随机点。收集足够的点，你可以计算出盒子的边缘方向和尺寸。

Falcon/Dilithium 如何避免：使用高斯采样（球面对称分布）+ 拒绝采样，签名分布是球形的，不泄漏基的形状。
