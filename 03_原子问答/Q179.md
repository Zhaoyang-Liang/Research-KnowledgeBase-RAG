# 重线性化中为什么需要 bit decomposition？不用分解直接乘行不行？

重线性化的目标：把 α₂s² 替换为某种线性组合（用 evk 的加密）。

直接乘不可行：(1) α₂ 是模 q 大数（~数百 bits），直接乘 evk 中的加密噪声 → 噪声膨胀 O(α₂·B_evk) → 解密失败。(2) evk = s² 的密文，噪声 ~ B_small。α₂·B_small ~ q → 完全淹没消息。

位分解解决：(1) 将 α₂ 按基 T 分解为 ℓ = ⌈log_T q⌉ 个小 digit：α₂ = Σ α_{2,i}·T^i。(2) 预发布 rlk_i ≈ T^i·s² 的密文组。(3) 用小 digit α_{2,i} 分别去乘对应 rlk_i，再加总。

噪声 = Σ α_{2,i}·B_rlk ≤ T·ℓ·B_rlk（保守）或 √ℓ·B_rlk（subgaussian），远小于 α₂·B_small。这就是位分解的根本原因：用多个小乘替代一个大乘，控制噪声增长。
