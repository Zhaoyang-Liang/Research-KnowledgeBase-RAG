# Falcon签名方案是什么？它和Dilithium有什么区别？

Falcon 和 Dilithium 都是 NIST 标准化的后量子签名方案，都基于格密码，但设计原理不同。

Falcon：(1) 基于 GPV 框架（Gentry-Peikert-Vaikuntanathan 的高斯采样陷门），使用 NTRU 格。(2) 签名 = 用陷门（Falcon tree + ffsampling）对消息哈希做高斯采样，输出短签名。(3) 优点：签名和公钥大小极短（~666-1280 bytes），适合带宽敏感场景。(4) 缺点：高斯采样实现复杂（需要高精度浮点或离散高斯），side-channel 防护难。

Dilithium：(1) 基于 Fiat-Shamir with aborts（Lyubashevsky 2009/2012），使用 MLWE 问题。(2) 签名 = 生成短承诺 → 哈希挑战 → 响应，如果响应不够短就重启（rejection sampling）。(3) 优点：实现简单（只用整数运算），无高斯采样，side-channel 友好。(4) 缺点：签名较大（~2420-4595 bytes）。

选择：Dilithium 更广泛部署（实现简单的优势），Falcon 在带宽和存储受限时更优。
