## 历史链条补充：批次编号说明

本知识库整理过程采用 Batch 分批处理。这里的 Batch 不是论文版本号，而是资料处理批次，用来记录不同类型材料的导入、阅读、卡片化、Q&A 化和 RAG 入库状态。

### Batch-01：早期核心材料与基础知识库初始化

Batch-01 是最早的一轮系统整理，主要处理抽象代数、FHE 基础、CKKS/BGV/BFV 基础、field switching、早期论文相关材料等。它生成了早期知识卡片 K001–K028，并形成了第一版术语表、公式表、原子问答和 P0 核实材料。

由于 Batch-01 是早期试运行阶段，后来专门生成了 `10_Batch01修正版/` 作为修正版历史快照。该目录现在不作为日常入口，只作为 archive / audit snapshot 保留，用于回溯早期 K001–K028、P0 核实、术语表、公式表和原子问答。

### Batch-03：当前论文相关补充材料与翻译笔记整理

Batch-03 主要处理当前论文相关的翻译笔记、规划文件、SlotToCoeff / CoeffToSlot 相关材料，以及部分代数基础补充。该批次重点是把翻译笔记和用户自己的论文规划区分开，避免把翻译笔记误当成原论文结论。

典型产物包括 K030–K036，以及相关 Q&A。该批次中许多材料被标记为 `translation_note` 或 `needs_original_paper_check`，表示如果用于正式论文，需要再对照原文确认。

### Batch-04：外部论文与 Related Work 材料入库

Batch-04 主要处理外部论文、讲义和 related work 材料，尤其是 BGV/BFV bootstrapping 讲义、GSW、FHE from LWE、BFV/BGV/CKKS 相关综述材料等。

该批次生成了 K037–K038 等文献型卡片，主要用于文献定位、背景补充和 related work，不直接作为当前论文 proof 的依据。BGV/BFV bootstrapping 讲义被作为重要参考源，但仍需区分 BGV/BFV context 和 CKKS context。

### Batch-05a：编码、SIMD、C2S/S2C、Slot Permutation、NTT/FFT/DFT

Batch-05a 是一个大批次，后来拆成 05a1、05a2、05a3 三个子批次。

#### Batch-05a1：CKKS 编码基础

主要处理 CKKS 编码、典范嵌入、逆典范嵌入、π⁻¹ 共轭补全、σ⁻¹ 插值、coefficient view / slot view 等内容。

典型卡片包括 K039–K043。该批次为后续 C2S/S2C、CKKS bootstrapping 和编码相关推导打基础。

#### Batch-05a2：SlotToCoeff / CoeffToSlot / C2S / S2C

主要处理 C2S/S2C 线性变换、M → U_ℓ → M⁻¹ 分解、槽表示与系数表示转换、BGV/BFV context 与 CKKS context 的差异。

典型卡片包括 K044–K049。该批次后来发现 C2S/S2C 方向存在术语混用风险，因此后续又做了 C2S/S2C 术语方向审计，并新增 K063 作为权威术语卡片。

当前全库统一规则是：

- C2S = CoeffToSlot = coefficient representation → slot representation
- S2C = SlotToCoeff = slot representation → coefficient representation

旧笔记中相反的 convention 只作为 historical/original_note_convention，不作为正式定义。

#### Batch-05a3：SIMD、Slot Permutation、NTT/FFT/DFT

主要处理 SIMD 编码、CRT slot、Frobenius 轨道、slot permutation、τ_j 自同构、NTT/FFT/DFT、Vandermonde/DFT/典范嵌入矩阵关系等内容。

典型卡片包括 K050–K055。其中 FFT/DFT/NTT 相关内容有部分 `low confidence` 或 `rough_note`，主要作为 intuition，不应直接作为正式论文结论。

### Batch-05b1：FHE 方案总论、KeySwitch、ModSwitch、Rescale

Batch-05b 原计划处理 FHE 方案总论、噪声、安全、参数等内容。由于噪声分析涉及当前论文核心 proof，后来先只完成了 05b1。

Batch-05b1 主要处理：

- Gentry09 / BGV / BFV / CKKS 总览；
- BGV vs BFV 高低位区别；
- FHE 同态计算流程；
- KeySwitch / Relinearization；
- ModSwitch vs KeySwitch；
- ModSwitch vs Rescale。

典型卡片包括 K056–K062，以及相关 Q&A。该批次的内容主要是通用 FHE 知识，可以作为正式知识库背景使用，但涉及当前论文关系的部分需要 human review。

### Batch-05b2：噪声深入分析，当前暂停

Batch-05b2 原计划深入处理噪声分析、安全参数、正确性证明和当前论文的 noise theorem。但在预盘点阶段发现，当前论文噪声分析分成两层：

1. 通用 FHE 噪声知识；
2. 当前论文专属的 Split/Merge/Ring Switching/leaf bootstrapping 噪声问题。

由于其中 reduced-Q leaf bootstrapping、leaf error aggregation、formal noise theorem 等直接影响论文主定理和 proof strategy，所以 Batch-05b2 暂停，等待作者先做决策。

当前相关文件包括：

- `噪声分析作者决策页.md`
- `噪声与正确性缺口清单.md`
- `Batch05b2_pre_噪声分析双层盘点.md`
- `11_知识入库接口/噪声分析知识沉淀候选.md`

这些内容目前属于 candidate / defer，不应作为 validated conclusion。

### Batch-05c：RLWE、格密码、CVP/SVP/Babai、重线性化、后量子材料

Batch-05c 主要处理 RLWE、LWE、ideal lattice、CVP/SVP、Babai 最近平面算法、LWE to SVP 归约、重线性化 bit decomposition，以及部分 Falcon/NTRU/签名材料。

典型卡片包括 K065–K069。该批次主要进入 RLWE / 格密码 / 后量子知识库，其中 K068 与 FHE 重线性化直接相关。

Falcon、NTRU、Klein-GPV 等材料目前只作为 side_material / future topic，不继续展开。

### Batch-06：实验数据整理，当前暂缓

Batch-06 原计划处理实验数据，例如：

- `time-logn16.txt`
- `简单正确性验证.txt`
- `简单总结表格.md`

但这些实验数据与当前论文贡献、噪声分析、正确性声明直接相关。因此在作者未确认 Batch-05b2 的噪声决策前，Batch-06 暂缓。

当前原则是：

- 已验证实验结论可以进入正式知识库；
- 未验证实验观察只能进入论文协作区或 candidate_knowledge；
- 不应由 AI 自动把实验日志解释成论文结论。

### RAG Baseline v1.0

RAG Baseline v1.0 是当前已经可用的检索系统，不是一个 Batch。它基于已经整理好的 ready chunks 构建。

当前配置：

- ready chunks：467
- embedding provider：SiliconFlow
- embedding model：BGE-M3 / Pro/BAAI/bge-m3
- 检索方式：dense embedding + BM25 + exact ID match
- fusion：RRF
- vector DB：暂不使用
- reranker：暂不使用
- LLM generation：暂不接入
