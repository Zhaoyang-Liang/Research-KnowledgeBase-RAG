# 论文想法沉淀模板

> 用于将论文项目中的核心想法沉淀为知识库候选

## 沉淀步骤

### 1. 识别可沉淀内容

在论文项目中找到:
- 通用性定义
- 可复用的 construction
- 可复用的 proof trick
- 有价值的 negative result

### 2. 填写沉淀申请

```json
{
  "candidate_id": "cand_NNN",
  "paper_id": "paper_2027_eurocrypt_fhe",
  "idea_id": "idea_001",
  "title": "想法标题",
  "core_content": "核心内容",
  "potential_reuse": "在什么场景下可复用",
  "verified": false,
  "verification_method": "实验 / 证明 / 专家确认"
}
```

### 3. 放入候选箱

- 写入 `11_知识入库接口/新知识候选箱.md`
- 标注来源 paper_id 和 idea_id

### 4. 审核

- 检查是否与其他知识冲突
- 检查是否已有类似知识
- P0 级别的内容优先审核

### 5. 发布

- 验证通过后发布到正式知识库
- 生成 card_id
- 更新术语表/公式表/关系图
- 保留回链到原论文项目
