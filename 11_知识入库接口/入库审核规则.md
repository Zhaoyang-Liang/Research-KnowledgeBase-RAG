# 入库审核规则

> 版本: v1 | 生成: 2026-05-04

## 可入库的条件 (满足任一即可)

1. 来自已验证的原文/文献结论
2. 来自用户笔记但经过原文对照验证
3. 来自论文项目但已被证明/实验验证
4. 是标准教科书中确认的基础知识

## 不可入库的条件

1. 仅来自 Qclaw 推理未经验证
2. 是论文草稿中的未确认想法
3. 与已有知识卡片明确矛盾
4. 来源不明确（无 source_id）
5. 仅适用于当前论文的局部定义/notation

## 需要特别标注的入库

| 情况 | 标注 |
|------|------|
| 笔记推导 | claim_source_type: "我的笔记" |
| Qclaw 推理 | claim_source_type: "Qclaw推断" |
| 跨源合成 | claim_source_type: "Qclaw推断（跨源合成）" |
| 未完全验证 | confidence: "low/medium" |
| 论文专有 notation | used_in_paper: true |

## negative_result 入库

失败的尝试也有价值:
- 标注 status: "negative_result"
- 说明: 尝试了什么、为什么失败了
- 避免他人重复同样错误
- 不进入 RAG 但保留在知识库
