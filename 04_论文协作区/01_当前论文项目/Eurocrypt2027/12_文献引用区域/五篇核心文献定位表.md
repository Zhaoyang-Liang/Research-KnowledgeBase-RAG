> paper_id: paper_2027_eurocrypt_fhe  
> 目的：为新初稿重写固定 related work 边界，避免把本文写成 CKKS / ring switching / HERMES / PaCo / subring secret encapsulation 的简单重复。

## 0. 本文一句话定位

本文研究的是：

```text
传统 CKKS bootstrapping core
  C2S_N -> EvalMod_N -> S2C_N
是否可以沿 coefficient/module split 分解为多个 leaf core。
```

本文不是新 CKKS scheme，不是发明 ring switching，不是 ring packing，不是 partial CoeffToSlot 新 bootstrapping，也不是 subring secret acceleration。

更准确的 novelty 应写成：

```text
Coefficient/module decomposition is compatible with the C2S-EvalMod-S2C sandwich structure of CKKS bootstrapping, so the large-ring core can be factored into independent subring cores without restoring big-ring slots.
```

## 2. 逐篇定位

### 2.1 CKKS17

**应引用的内容**

- CKKS 支持 complex approximate arithmetic。
- 明文向量经 canonical embedding / inverse transform 编码为 polynomial。
- scale 与 rescale 管理近似精度和 modulus chain。
- CKKS ciphertext 满足近似解密关系，噪声作为误差的一部分。

**本文不能说**

- 不能把本文贡献写成 CKKS approximate arithmetic 本身。
- 不能把 CKKS encoding/decoding 和 bootstrapping C2S/S2C 混成同一个概念。

**本文应如何承接**

CKKS17 是基础层。本文只需要在 preliminaries 中建立：

```text
ct decrypts to a plaintext polynomial P(X) up to scale and error;
bootstrapping later moves coefficient-like data into slots via C2S, applies EvalMod coordinate-wise, and moves back via S2C.
```

---

### 2.2 Ring Switching old

**应引用的内容**

- 大环 polynomial 可以按 coefficient residue class 拆成多个小环 polynomial。
- 形如：

```text
a(X) = sum_{r=0}^{k-1} X^r a^{(r)}(X^k)
```

- 该 decomposition 是 linear module decomposition。
- ciphertext-level ring switching 不是免费重排，需要 key switching / secret switching / noise analysis。

**本文不能说**

- 不能声称本文发明了 coefficient decomposition。
- 不能声称 ring switching 本身是本文贡献。
- 不能把明文系数拆分直接等同于密文分量公开抽取。

**本文应如何承接**

本文应写：

```text
We use the standard coefficient/module decomposition underlying ring switching as the semantic target of RSDown/RSUp. Our contribution is to show that this decomposition is compatible with the C2S-EvalMod-S2C core of CKKS bootstrapping.
```

**关键边界**

Ring switching old 关心的是如何从 big ring ciphertext 到 small ring ciphertext，并在 packed setting 下处理 slot distribution。本文关心的是：得到 leaf ciphertexts 后，是否需要恢复 big-ring slots。本文答案是 no。

---

### 2.3 HERMES23

**应引用的内容**

- HERMES 是高相关现代系统文献。
- 它使用 ring switching、bootstrapping、MLWE midpoint 来做 efficient ring packing。
- 它的目标是 LWE/MLWE ciphertexts 到 RLWE/CKKS ciphertext 的 packing/transciphering。
- 它强调 FHE ring packing 输出应支持后续 bootstrappable CKKS computations。

**本文不能说**

- 不能把本文写成 HERMES 的直接改进。
- 不能把本文任务说成 ring packing。
- 不能把 HERMES 的 HalfBTS 叙事照搬成本文贡献。

**本文应如何区分**

建议 related work 写法：

```text
HERMES uses ring switching and bootstrapping as tools for ring packing and transciphering, starting from many LWE/MLWE-format ciphertexts and producing an RLWE/CKKS ciphertext. In contrast, our input is already a CKKS/RLWE ciphertext, and our goal is to factor its own CKKS bootstrapping core into subring leaf cores. We do not solve LWE-to-RLWE packing; instead, we study a compatibility theorem for the traditional CKKS C2S-EvalMod-S2C sandwich.
```

**与本文潜在连接**

HERMES 支撑本文使用 ring switching 作为已知工具，但本文的 theorem 不依赖 MLWE midpoint 或 ring packing column/row methods。

---

### 2.4 PaCo25

**应引用的内容**

- PaCo 是新式 CKKS bootstrapping，使用 partial CoeffToSlot。
- 它通过 blind rotations、circle group modular additions 和 alternative ring structures 重写 decryption/bootstrap circuit。
- PaCo 关注 logarithmic complexity in number of complex slots，并强调 parallel variant。

**本文不能说**

- 不能把本文与 PaCo 都笼统写成 partial C2S。
- 不能声称本文也重写 decryption equation。
- 不能说本文避免 EvalMod 近似，本文仍保留传统 EvalMod。

**本文应如何区分**

建议 related work 写法：

```text
PaCo changes the CKKS bootstrapping algorithm by reformulating the decryption equation and using partial CoeffToSlot to enable blind rotations and circle-group modular additions. Our construction is orthogonal: it keeps the conventional C2S-EvalMod-S2C core and changes its execution granularity via coefficient/module split. Thus our theorem is about factoring the existing sandwich, not replacing EvalMod or designing a new decryption circuit.
```

**可借鉴但需谨慎**

- PaCo 中对 C2S/S2C、Vandermonde decomposition、bit-reversal 和 alternative ring structures 的讨论可帮助写 preliminaries。
- 但本文的 `B_k` / no-`B_k` 讨论不能被写成 PaCo 的 partial C2S。

### 2.5 Subring Secret Encapsulation / Anyu Wang

**应引用的内容**

- 该文解决 dense-secret bootstrapping 效率问题。
- 它在 bootstrapping 前切换到 subring dense secret。
- subring secret 的 smaller Hamming weight 加速 EvalMod / digit removal。
- subring secret 的代数结构可 hoist C2S/S2C 中的 key switching。
- 它明确区分自己与 ring switching：不需要 unpack into low-dimensional sub-ciphertexts and repack。

**本文不能说**

- 不能把本文写成 subring secret encapsulation。
- 不能把本文的 leaf ciphertext decomposition 和它的 secret switch 混淆。
- 不能借用它的 dense-secret security claim 到本文 leaf ciphertexts。

**本文应如何区分**

建议 related work 写法：

```text
Subring secret encapsulation switches the secret to a dense subring secret before bootstrapping and accelerates EvalMod and C2S/S2C through smaller secret weight and hoisted key switching. Our approach instead decomposes the ciphertext/message semantics into multiple subring leaf ciphertexts and runs leaf bootstrapping cores. Therefore, subring secret encapsulation is subring-secret acceleration, whereas our work is subring-ciphertext/core decomposition.
```

**重要风险**

该文可能是 reviewer 最容易拿来比较的近邻。本文必须强调：

- 它仍对同一个 ciphertext 做 bootstrapping，只是 secret 换成 subring secret。
- 本文生成多个 leaf ciphertexts，各 leaf independently execute C2S-EvalMod-S2C。
- 它的安全来自 dense subring secret RLWE；本文 leaf security 必须单独估计，不可继承。

## 3. Related Work 推荐结构

### 3.1 CKKS bootstrapping

引用 CKKS17 和后续 CKKS bootstrapping 线。这里只需说明传统 CKKS bootstrapping core 的基本结构：

```text
ModRaise -> C2S -> EvalMod -> S2C
```

本文贡献应接在这里：

```text
We retain this conventional core and prove that the core itself admits a coefficient-split factorization.
```

### 3.2 Ring switching and ring packing

先引用 ring switching old，再引用 HERMES。

逻辑：

```text
Ring switching provides the algebraic and ciphertext-level machinery for moving between rings.
HERMES shows modern ring switching/ring packing can be practically useful in CKKS-related systems.
Our work uses ring switching as a tool but addresses a different problem: factoring CKKS bootstrapping of an existing RLWE ciphertext.
```

### 3.3 Subring-based bootstrapping acceleration

引用 AnyuWang。

逻辑：

```text
Subring secret encapsulation accelerates bootstrapping by switching secrets, not by decomposing the bootstrapping core into leaf ciphertexts.
```

### 3.4 New CKKS bootstrapping designs

引用 PaCo。

逻辑：

```text
PaCo redesigns bootstrapping via partial CoeffToSlot and blind rotations.
Our method is orthogonal because it preserves the conventional EvalMod path.
```

## 4. 贡献措辞边界

### 可以写

- coefficient-split factorization of the CKKS bootstrapping core
- no-`B_k` subring-factored CKKS bootstrapping
- compatibility of coefficient/module split with C2S-EvalMod-S2C
- implementation evidence in Lattigo under shared-basis parameters

### 暂时不要写

- secure speedup under final parameter set
- reduced-Q leaf bootstrapping
- complete noise theorem
- ring switching is new
- slot-preserving split is achieved for free
- PaCo-like partial C2S
- HERMES-like ring packing
- subring secret encapsulation
