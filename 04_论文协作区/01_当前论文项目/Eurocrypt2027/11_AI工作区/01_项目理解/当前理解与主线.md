# 当前理解与主线

> 2026-05-04 | 基于初稿.pdf (src_000031)

## 核心问题

大环 CKKS bootstrapping core S2C_N ∘ EvalMod_N ∘ C2S_N 能否分解为 k 个独立的小环 bootstrapping cores？

答案：**可以**。

## 核心构造

设 N = kn。Coefficient/module decomposition:
```
P(X) = Σ_{r=0}^{k-1} X^r P_r(X^k)
其中 Y = X^k，P_r(Y) ∈ R_{q,n} = Z_q[Y]/(Y^n+1)
```

整体结构:
```
RSUp_{n→N}
  ∘ Split_k           // coefficient decomposition (no key switching)
  ∘ ⊕_r C2S_n         // leaf-wise CoeffToSlot
  ∘ ⊕_r EvalMod_n     // leaf-wise approximate modular reduction
  ∘ ⊕_r S2C_n         // leaf-wise SlotToCoeff
  ∘ Merge_k           // coefficient merge (no key switching)
  ∘ RSDown_{N→n}
```

等价于传统 core: S2C_N ∘ EvalMod_N ∘ C2S_N

## 关键特征

1. **不是 slot-preserving split** — split 后不保留 big-ring slot values
2. **系数层面兼容** — coefficient split 与逐坐标 EvalMod 兼容
3. **每个 leaf 独立** — 各个 leaf 可独立执行 bootstrapping core
4. **RSUp/RSDown** — ciphertext-level ring switching（含 key switching，有额外噪声）

## γ_impl 是什么

γ_impl 是 Lattigo 实现层的 normalization correction factor，不是数学主定理的一部分。
来源：LogMessageRatio 调整以匹配 ScaleDown/EvalMod/SlotsToCoeffs 的数值尺度。

## R 与 R^∨ 是什么

初稿使用 R_{q,N}^2（实现层记号）。
GHPS 使用 (R_q^∨)^2（RLWE dual 记号）。
这是符号体系差异，不是方案错误。需要在 Preliminaries 加 notation caveat。
