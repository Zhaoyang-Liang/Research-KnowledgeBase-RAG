## 1. 当前论文真正的主张

**核心主张**:
> 大环 CKKS bootstrapping core S2C_N ∘ EvalMod_N ∘ C2S_N 可以通过
> coefficient/module decomposition (Split_k) 分解为 k 个独立的 leaf bootstrapping cores
> S2C_n ∘ EvalMod_n ∘ C2S_n，再用 Merge_k 恢复。

形式化:
```
S2C_N ∘ EvalMod_N ∘ C2S_N =
  Merge_k ∘ (⊕_{r=0}^{k-1} S2C_n ∘ EvalMod_n ∘ C2S_n) ∘ Split_k
```

**关键特征**:
- Split 后**不恢复** big-ring slots
- 使用 subring ring switching（HERMES-style）
- 每个 leaf 独立执行完整 bootstrapping core

## 2. 当前论文**不是在做什么**

| 不做 | 说明 |
|------|------|
| 不重写 CKKS decryption | 保留传统 C2S/EvalMod/S2C框架 |
| 不改变 EvalMod 内部 | 不替换近似多项式 |
| 不做 slot-preserving split | 不在split后恢复原始slot values |
| 不做 pure ring packing | 不是把多个独立密文pack成一个（那是HERMES） |
| 不替代 PaCo | 不重写bootstrapping的结构 |
| 不优化单个线性变换 | 是整个core的分解 |

## 3. 与 HERMES 的区别

| | HERMES | 本文 |
|------|--------|------|
| 输入 | 多个LWE密文 | 单个CKKS密文 |
| 目标 | Packing + transciphering | 刷新单个密文自身 |
| Ring switching | 核心贡献 | 作为工具使用 |
| 是否恢复slots | 需要重新排列 | 不恢复slots |
| 使用 | Ring switching + MLWE | 可引用HERMES但不声称贡献 |

## 4. 与 PaCo 的区别

| | PaCo | 本文 |
|------|------|------|
| 方法 | Partial CoeffToSlot + blind rotations | 传统 C2S/EvalMod/S2C |
| 加速机制 | 结构化密钥 + circle-group | 子环分解 |
| 与本文关系 | **正交** — 不重写core内部 | 保留传统core，改变粒度 |

## 5. 与 Subring Secret Encapsulation 的区别

| | Subring Secret Encapsulation | 本文 |
|------|------|------|
| 作用 | 密钥加速（subring-secret） | 密文分解（subring-ciphertext） |
| 效果 | 降低 EvalMod 成本 | 将core分成k个独立task |
| 关系 | **正交** — 可叠加使用 |

## 6. 与传统 CKKS Bootstrapping 优化的区别

**正交关系**: 传统工作优化 pipeline 内部的某个矩阵或 approximation，
本文改变的是**core的执行粒度**（从大环到小环）。
