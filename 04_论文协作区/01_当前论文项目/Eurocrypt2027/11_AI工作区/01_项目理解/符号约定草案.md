## 一、主记号建议

### 环与域

| 符号 | 定义 | 来源 |
|------|------|------|
| `m` | 主分圆指数 (power-of-two) | GHPS + Geelen |
| `m₀` | 子分圆指数，`m₀ | m` | GHPS |
| `N` | `N = φ(m) = m/2` | 标准 |
| `N₀` | `N₀ = φ(m₀) = m₀/2` | 标准 |
| `K = Q(ζ_m)` | 分圆数域 | GHPS |
| `K₀ = Q(ζ_{m₀})` | 子域 | GHPS |

| `R₀ = Z[ζ_{m₀}]` | 子环 | 标准 |
| `R_q = R/qR` | 模 q 商环 | Geelen + 实现 |

### 密文与噪声空间

| 符号 | 定义 | 使用场景 |

## 二、何时使用 R_q² vs (R_q^∨)²？

| 场景 | 使用 | 理由 |
|------|------|------|
| 算法伪代码 | `R_q²` | 实现友好 |
| 同态操作定义 | `R_q²` | 与 BGV/BFV 文献一致 |
| SlotToCoeff / CoeffToSlot | `R_q²` | Geelen 的框架 |
| Plaintext encoding | `R_{p^e}` | 标准 BGV/BFV |
| GHPS field switching 引用 | `(R_q^∨)²` | 保留原文记号 |
| Field switching correctness proof | `(R_q^∨)²` | trace 需要 dual |
| Noise analysis (field switching) | `R^∨` | Good Bases 适用 |
| Security proof (RLWE) | `R^∨` | GHPS 的安全归约 |

## 三、如何解释二者的关系？

### 建议在 Preliminaries 中增加

```text
Remark (Dual/codifferent convention).
GHPS 2013 采用 RLWE 对偶表述，将密文空间写为 (R_q^∨)^2，
其中 R^∨ = {a ∈ K : Tr_{K/Q}(aR) ⊆ Z} 是 R 的 codifferent。
R^∨ 是主分式理想: R^∨ = t⁻¹R 对某 t ∈ R。乘以 t 给出
R^∨ → R 的 R-模同构。

本文在算法层采用 R_q² 记号以贴近 BGV/BFV 实现文献 [Geelen, SEAL]。
当引用 GHPS 的 correctness/noise/security proof 时，
我们切换到 GHPS 的 (R_q^∨)² 记号以保留 dual 结构。
在实现中，通过固定 decoding basis，dual 元素可表示为
与 R 元素相同的系数向量——这只是表示层面的便利，
不改变 underlying duality structure。
```
