## 与论文材料区的关系

```
论文材料区 (01–10)         AI工作区 (11)
┌─────────────────┐       ┌─────────────────┐
│ 作者写论文用     │       │ AI 理解/检查用   │
│                 │       │                 │
│ 01_论文正文     │ ←───→ │ 01_项目理解      │
│ 02_核心构造     │ ←───→ │ 03_P0核实        │
│ 03_证明系统     │ ←───→ │ 04_证明与噪声检查 │
│ 05_参数与安全   │ ←───→ │ 04_证明与噪声检查 │
│ 06_Related_Work │ ←───→ │ 05_Related_Work辅助│
│ 08_待确认问题   │ ←───→ │ 02_待办与人工确认 │
│ 09_知识沉淀候选 │ ←───→ │ 06_知识沉淀候选  │
└─────────────────┘       └─────────────────┘
```

- **作者** 优先看 01–10 内的材料
- **AI** 首次接手先看 `00_接手说明/`，然后按需查对应子目录
- AI 查找详细材料时，通过 `00_接手说明/核心材料索引.md` 跳转到 01–10 各目录
- 根目录只有一个 `README.md` + 11 个子目录，不再堆放散文件

## ⚠️ 重要提醒（AI 必读）

1. **candidate knowledge 不是论文结论**：`06_知识沉淀候选/` 中的内容全部未 validated，不得作为论文 claim
2. **噪声分析 A1/A2/A3 未决策**：`04_证明与噪声检查/噪声分析作者决策页.md` 中的 3 个问题在作者决策前，噪声方向不确定
3. **实验数据未经作者确认**：`../04_实验实现/` 中的实验结果是 implementation observation，非论文最终表格
4. **C2S/S2C 术语规范**：按 PaCo 论文，C2S=CoeffToSlot，S2C=SlotToCoeff
5. **γ_impl 是实现约定不是定理**：放 implementation section，不放 theorem
