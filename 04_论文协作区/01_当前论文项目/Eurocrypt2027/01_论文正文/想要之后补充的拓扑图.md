Let N = k n and
p = (a_0, a_1, ..., a_{N-1}).

Arrange p as an n x k rectangle by rows:

row j, col r  =  a_{r + j k}

So the rectangle is

```txt
          col 0        col 1        ...      col r        ...    col k-1
row 0      a_0          a_1         ...      **a_r**      ...    a_{k-1}
row 1      a_k          a_{k+1}     ...      **a_{r+k}**  ...    a_{2k-1}
row 2      a_{2k}       a_{2k+1}    ...      **a_{r+2k}** ...    a_{3k-1}
...
row j      a_{jk}       a_{jk+1}    ...      **a_{r+jk}** ...    a_{(j+1)k-1}
...
row n-1    a_{(n-1)k}   a_{(n-1)k+1}...      **a_{r+(n-1)k}** ... a_{nk-1}
```

Hence S_r p is exactly the r-th column:

S_r p = (a_r, a_{r+k}, a_{r+2k}, ..., a_{r+(n-1)k}).

Equivalently, P_r(Y) collects all coefficients whose indices are congruent to r mod k.
