# 10_发布快照

## 用途
存放论文草稿的阶段性版本快照。当前为空。

## 发布计划

| 版本 | 内容 | 触发条件 |
|------|------|----------|
| v0.1_draft | 初稿 + 构造框架 | 构造与算法初步完成 |
| v0.2_proof_complete | 所有主定理证明完成 | A1/A2/A3 决策后 + 证明补全 |
| v0.3_experiment | 实验数据完整 | benchmark 完成 |
| v0.4_related_work | Related Work 完整 | 文献比较完成 |
| submission_candidate | 投稿候选版 | 全部章节完成 + 人工审校 |

## 注意事项
- **当前不要自动生成发布快照**
- 只有达到阶段性目标时才打包快照
- 快照应包含：论文 PDF + TeX 源文件 + 图表 + 参考文献
- 生成方式：从各子目录收集最终版本 → 打包为 tar.gz 或单目录
