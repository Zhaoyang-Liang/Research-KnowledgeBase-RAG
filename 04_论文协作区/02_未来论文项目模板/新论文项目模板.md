## 目录结构

新论文项目默认采用以下结构：

```
论文项目名/
├── 00_项目管理/      # paper_id, idea_id 规则
├── 01_论文正文/      # LaTeX 草稿、写作路线
├── 02_核心构造/      # 算法构造、推导材料
├── 03_证明系统/      # 证明草稿、proof gap 清单
├── 04_实验实现/      # 实验代码、benchmark 数据
├── 05_参数与安全/    # 噪声分析、安全参数
├── 06_Related_Work/  # 参考文献、定位表
├── 07_图表与表格/    # 论文图表
├── 08_待确认问题/    # 待办和问题
├── 09_知识沉淀候选/  # candidate knowledge
├── 10_发布快照/      # 投稿版本快照
├── 11_AI工作区/      # AI 接手说明、项目理解、待办、检查
│   ├── 00_接手说明/
│   ├── 01_项目理解/
│   ├── 02_待办与人工确认/
│   ├── 03_P0核实/
│   ├── 04_证明与噪声检查/
│   ├── 05_Related_Work辅助/
│   ├── 06_知识沉淀候选/
│   ├── 07_OpenClaw或外部AI交接/
│   └── 99_归档候选/
└── README.md
```

**规则**：
- 01–10 是论文材料区（作者写论文用）
- 11_AI工作区 是 AI 理解、协作、接手和检查区
  - `07_OpenClaw或外部AI交接/` 放 OpenClaw / 其他 AI 生成的接手说明、运行记录、整理报告；这些不是论文正文，只作为 AI 协作参考
- 根目录只保留 README.md + 一级目录，不堆散文件
- 每个目录必须有 README.md
- 特殊论文可新增或删减目录，但必须在 README 中说明
- AI 生成的一次性计划、审计、检查结果，应进入 11_AI工作区/99_归档候选 或 `../09_工作进度`，不散落在根目录和论文材料区
