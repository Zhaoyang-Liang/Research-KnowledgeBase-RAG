# 论文想法到知识库映射

> 版本: v1 | 生成: 2026-05-04

## 映射规则

论文项目中的内容可能沉淀为以下知识库内容:

| 论文内容 | 知识库目标 |
|----------|-----------|
| 新 construction | 03_FHE知识库 或 04_论文创作知识库 |
| 新 proof trick | 证明方法库 |
| 新定义/术语 | 术语表 + 03_FHE知识库 |
| 实验结果/benchmark | 04_实验数据 |
| related work 对比 | 文献关系图 |
| 失败尝试 | negative_result (不推荐路线) |
| 参数选择经验 | 参数知识库 |
| 新 notation | 术语表 (标注论文专用) |

## 沉淀前检查

1. 内容是否可跨论文复用？ → 是 → 可沉淀
2. 是否是当前论文局部定义？ → 是 → 留在论文区
3. 是否已经验证？ → 未验证 → 标注 needs_validation
4. 是否有通用价值？ → 是 → 优先沉淀
