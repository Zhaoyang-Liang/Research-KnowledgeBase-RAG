# Batch 处理优先级

> 版本: v1 | 生成: 2026-05-04

## 优先级排序

```text
P0: Batch-02 (P0核实) → Batch-03 (当前论文 core)
P1: Batch-04 (FHE文献) / Batch-05 (Bootstrapping) / Batch-07 (分析模块)
P2: Batch-06 (格密码) / Batch-08 (实现) / Batch-09 (文献管理)
P3: Batch-10 (RAG入库)
```

## 执行策略

1. **P0 优先**: Batch-02 和 Batch-03 必须先完成，不因 P2/P3 量大而延迟
2. **P1 可并行**: Batch-04/05/07 之间无严格依赖，可在 P0 完成后并行
3. **P2 轻处理**: Batch-06/08/09 不当前主线，可以做轻处理
4. **P3 待所有 P0 解决**: Batch-10 在所有 P0 核实后启动

## 论文协作区特殊流程

论文协作区（Batch-03）产出的知识需经过沉淀流程：
```text
Batch-03 论文核心 idea → 11_知识入库接口 → 候选/验证 → 正式知识库
```

不要直接把论文草稿当成确定知识。
