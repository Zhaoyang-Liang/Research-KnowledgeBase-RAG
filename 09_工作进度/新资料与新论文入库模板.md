# 新资料与新论文入库模板

> v1 | 2026-05-04 | 可直接复制使用

---

## 模板 1: 新外部论文入库

```text
请处理以下外部论文:

论文文件: [路径]
论文标题: [标题]
作者/年份: [作者, 年份]
论文类型: foundational / related_work / background / side_material

请执行:
1. 复制到 01_源文件库/ 合适分类
2. 生成 source_id (src_XXXXXX)
3. 轻读/精读决策:
   - foundational → 精读
   - related_work → 精读(核心段)
   - background → 轻读
   - side_material → 轻读或跳过
4. 生成内容:
   - 文献摘要 (knowledge card)
   - 核心技术卡片 (如有新方案/新技术)
   - 原子问答 (5-10条)
   - related work 定位 (与当前论文关系)
5. 标记是否进入长期知识库

注意:
- 如果与当前论文无关，标记 background，不要过度精读
- 不要把 side_material 当成 foundational paper
```

## 模板 2: 新理论笔记入库

```text
请处理以下理论笔记:

笔记文件: [路径]
主题: [抽象代数 / RLWE / FHE / 证明推导 / 参数分析]
笔记类型: 个人推导 / 课堂笔记 / 阅读笔记 / 证明草稿

请执行:
1. 复制到 01_源文件库/01_抽象代数/ 或对应分类
2. 生成 source_id
3. 判断是否可复用知识:
   - 可复用 → 生成概念卡片 + 公式表 + 术语
   - 个人草稿 → 标记 needs_human_review
4. 关联: 抽象代数 → FHE 关联 / 当前论文关联
5. 不要宣称草稿中的证明已正确
```

## 模板 3: 新论文项目启动

```text
请启动新论文项目:

论文短名: [如: Eurocrypt2028, PKC2027]
论文标题: [暂定标题]
输入材料: [初始文件的路径列表]

请执行:
1. 创建 04_论文协作区/[短名]/ 目录
2. 生成 paper_id (paper_XXXX_shortname)
3. 生成 idea_id 规则 (idea_001, idea_002, ...)
4. 生成 7 个核心入口文件:
   - 项目总览.md
   - AI协作上下文.md
   - 核心材料索引.md
   - 当前理解与主线.md
   - 待办与人工确认.md
   - 证明状态简表.md
   - 知识沉淀候选.md
5. 导入初始材料到 01_源文件库
6. 明确 AI 协作边界

注意:
- 不要把旧论文的材料和新论文混淆
- 不要默认生成大量空文件
- 不自动发布到长期知识库
```

## 模板 4: 论文想法沉淀入库

```text
请把以下论文想法沉淀为知识库候选:

论文项目: [paper_id]
来源位置: [论文第X节 / 实验Y / 讨论Z]
想法内容: [简短描述]

请执行:
1. 在论文项目的 知识沉淀候选.md 中注册
2. 在 11_知识入库接口/新知识候选箱.md 中注册
3. 标记:
   - knowledge_id: cand_XXX
   - paper_id
   - 知识类型 (construction/proof_trick/notation/...)
   - 状态: candidate_knowledge, needs_validation
4. 不要直接发布到正式知识库

注意:
- 论文草稿中的 idea 必须经过作者确认才能变成 validated
- 不要把 candidate 标成 validated
```
