# Research-KB-RAG 总工作流说明

> v1 | 2026-05-04

## 系统全景

```
临时资料池 (~/Desktop/Eurocrypt 2027/)
  │
  ▼ 导入 (复制，不移动不删除)
01_源文件库/  (来源分类，source_id 注册)
  │
  ▼ Batch 处理 (轻读→精读决策→卡片→问答→术语→公式→关联)
  │
  ├──→ 02_知识卡片/  (JSON+MD，概念卡片)
  ├──→ 03_原子问答/  (问答对，来源映射)
  ├──→ 05_知识关联/  (术语、公式、概念依赖、参数关系、交叉引用)
  │
  ▼ 发布 (验证后)
03_FHE知识库/  (正式知识区，按主题分类)
  │
  ▼ 准备 (不自动 embedding)
06_RAG入库准备/  (chunk 策略、embedding ready 材料)

────────────────────────────────────
论文协作区 (独立循环)
────────────────────────────────────
04_论文协作区/
  │
  ├── 当前论文项目  (读→写→proof→实验)
  │     │
  │     └── 知识沉淀候选
  │           │
  │           ▼ candidate_knowledge
  └── 未来论文项目
  │
  ▼
11_知识入库接口/  (论文产生的候选知识)
  │
  ▼ 作者确认 → validation → publish
长期知识库 (03_FHE知识库/)
```

## 核心原则

1. **知识库不是只读外部论文** — 论文项目也会产生新知识（proof trick、实验结论、参数经验、失败尝试）
2. **论文草稿 ≠ validated knowledge** — 必须经过 candidate → validation → publish
3. **AI 整理 + 作者确认** — AI 整理归类和风险提醒，最终判断由作者做
4. **不自动 embedding** — RAG ready 材料准备好，作者决策何时进入向量库
5. **不删不改原文件** — 只在 KB 工作区内操作

## 两个循环

| 循环 | 输入 | 输出 | 触发 |
|------|------|------|------|
| 知识库循环 | 外部论文/笔记/实验 | 知识卡片/问答/术语/公式/关联 | 新 Batch |
| 论文协作循环 | 论文材料/证明/实验 | 论文 + candidate knowledge | 论文项目 |

两个循环通过 `11_知识入库接口` 连接。
