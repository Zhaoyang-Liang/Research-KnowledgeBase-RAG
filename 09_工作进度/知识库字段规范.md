## 5. 重要规则

### 关于原文与翻译

```
translation_note ≠ 原文依据
translation_note = 辅助理解，引用前必须核原文
```

### 关于 candidate knowledge

```
candidate_knowledge ≠ validated knowledge
candidate_knowledge = 等待验证的知识候选，不可直接用于论文引用
```

### 关于论文专属内容

```
论文项目专属分析 ≠ 长期知识库内容
论文专属分析应留在 04_论文协作区/
通过 candidate 机制经作者确认后，方可进入正式知识库
```

### 关于论文 idea → 长期知识库

```
论文 idea 默认 can_be_promoted_to_kb = false
论文 idea 默认 rag_status = defer
只有经作者确认并完成验证后，才能：
  1. 生成正式知识卡片
  2. 发布到长期知识库
  3. 更新 rag_status 为 ready
negative_result 和 deprecated idea 可作为历史参考保留，但需明确标记
```

### 关于 human review

```
✅ 不强制 review：有完整源文件的背景知识卡片
⚠️ 必须 review：影响当前论文 proof / noise / security / contribution 的内容
```

### 关于 confidence

```
high   = 用户笔记明确写出，源文件完整，无跨源推断
medium = 用户笔记有依据，但存在推断或综合的成分
low    = 跨多个源综合推断，或笔记本身为草稿/不完整
```

### 关于 rag_status

```
ready   = high/medium confidence + source_id 完整 + 非 human_review + 非 candidate + 非论文 idea
  → validated 通用知识 + paper_id=null
  → negative_result（已确认并标记）
defer   = low confidence / needs_review / translation_note / candidate / paper_project
  → 论文未验证 idea（paper_id 不为空、status != validated）
  → 论文草稿、proof sketch
  → candidate_knowledge（can_be_promoted_to_kb = false）
exclude = raw data / build artifact / duplicate / side_material / archive_only
```
