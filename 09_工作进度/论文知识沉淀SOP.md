# 论文知识沉淀 SOP

> 版本: v1 | 生成: 2026-05-04

## 概述

将论文写作中产生的新知识反向沉淀到长期知识库的标准流程。

## 流程

```text
1. 论文项目中产生想法/构造/证明/实验
2. 记录到论文协作区
3. 判断是否有跨论文长远价值
4. 如有 → 提交到 11_知识入库接口/新知识候选箱
5. 生成 candidate card
6. 标注来源 paper_id + idea_id
7. 标注验证状态
8. 审核通过 → 发布到正式知识库
9. 更新术语表/公式表/原子问答/关系图
10. 保留回链: 知识卡片 <-> 论文项目
```

## 状态流转

```text
draft_idea (论文草稿阶段)
  -> candidate_knowledge (候选)
  -> needs_validation (待验证)
  -> validated (已验证)
  -> published_to_kb (已发布)
```

## 每种状态的判断标准

| 状态 | 条件 |
|------|------|
| draft_idea | 论文项目中记录但未评估长期价值 |
| candidate_knowledge | 判断有长期价值，提交候选 |
| needs_validation | 候选但需证明/实验/对照原文 |
| validated | 通过验证 |
| published_to_kb | 已写入正式知识库 |
| deprecated | 后来发现不成立 |
| negative_result | 尝试过但不推荐 |

## 双向链接

沉淀后的知识卡片必须保留:
- `knowledge_origin: "my_paper_project"`
- `paper_id: "paper_2027_eurocrypt_fhe"`
- `idea_id: "idea_001"`

论文项目应记录:
- 已沉淀知识清单
- 待沉淀知识清单
