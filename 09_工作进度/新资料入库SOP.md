# 新资料入库 SOP

> 版本: v1 | 生成: 2026-05-04

## 概述

当用户提供新的 FHE 研究资料（论文 PDF、笔记 md、代码等）时，按此流程入库。

---

## 标准流程

### 1. 接收新资料

- 确认文件位置（临时资料池路径）
- 确认文件类型（pdf/md/tex/txt/代码/其他）
- 确认是否属于已有项目或新项目

### 2. 复制到源文件库

```text
cp <原路径> <KB>/01_源文件库/<子分类>/<文件名>
```

子分类选择:
- `01_抽象代数与代数数论/` — 代数基础
- `02_RLWE_格密码_后量子/` — 格密码
- `03_FHE总论与基础方案/` — FHE 总论
- `04_FHE核心技术模块/` — Bootstrapping/PaCo/Field Switching 等
- `05_实现与实验/` — 代码/实验数据
- `06_论文写作/` — 当前论文草稿
- `07_组会与讨论/` — 组会材料
- `08_文献与引用管理/` — 参考论文 PDF

### 3. 生成 source_id

在 `00_导入记录/原始路径到库内路径映射.jsonl` 追加:

```json
{
  "source_id": "src_NNNNNN",
  "original_path": "<原路径>",
  "kb_relative_path": "01_源文件库/<子分类>/<文件名>",
  "kb_category": "<分类>",
  "subtopic": "<子主题>",
  "import_time": "<ISO时间>"
}
```

source_id 规则: `src_` + 6 位递增数字（如 src_000028）

### 4. 判断 ingest_decision

| decision | 条件 | 处理 |
|----------|------|------|
| 精读 | 与当前论文直接相关或核心理论 | 全文精读 → 生成完整卡片 |
| 轻读 | 背景知识或旁线材料 | 扫描结构 → 生成简单卡片 |
| 跳过 | 构建产物/重复/无关 | 排除但不删除 |
| 待判断 | 不确定相关性 | 保留标记，后续决策 |

### 5. 生成知识卡片

根据 ingest_decision:
- 精读 → 完整卡片（knowledge_points + formulae + terminology + relations）
- 轻读 → 简单卡片（chinese_summary + 关键 knowledge_points）

### 6. 生成原子问答

- 基于知识卡片生成 5 条/卡
- 选择关键概念点设问

### 7. 更新术语表 + 公式表

- 新术语追加到术语表
- 新公式追加到公式表

### 8. 更新关系图

- 检查新内容是否与已有关系连接
- 更新 `05_知识关联/` 中相关文件

### 9. 标注 needs_human_review

以下情况标注 needs_human_review: true:
- 来自笔记而非原文的推导
- Qclaw 跨源推理
- 不确定术语使用
- 可能影响论文正确性的结论

### 10. 发布到正式知识库

- 按学科分类到 01/02/03/04 知识库
- 交叉引用使用索引引用（不复制正文）

### 11. 暂不自动 embedding

- 确认 P0 问题后再做 embedding
- 不在入库流程中自动触发 embedding
