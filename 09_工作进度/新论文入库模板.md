# 新论文入库模板

> 版本: v1 | 生成: 2026-05-04

## 三种处理模式

---

### 模式 A: 普通论文轻读入库

**适用**: 一般参考论文、背景资料、边缘相关文献

**处理目标**: 生成基础卡片，了解论文贡献和结论

**读取深度**: 
- 阅读 abstract + introduction + conclusion
- 扫描 main body 结构
- 提取关键定理和结论（不逐字精读）

**输出文件**:
- 1 张简单知识卡片（source_light_summary）
- 记录关键概念 3-5 个
- 标注与知识库的关联（或不关联）

**是否生成原子问答**: 否

**是否更新关系图**: 可选（仅当与已有知识有明确关联时）

**是否需要人工确认**: 否

**是否允许进入 RAG**: 否（需人工确认后再决定）

---

### 模式 B: 核心论文精读入库

**适用**: 当前论文直接依赖的参考论文（如 GHPS, PaCo, CKKS 原文）

**处理目标**: 深入理解论文，生成结构化知识卡片

**读取深度**:
- 全文精读（所有章节 + 附录）
- 提取关键定义、定理、公式、构造
- 理解证明思路和安全性分析
- 与已有知识卡片做交叉验证

**输出文件**:
- 多张知识卡片（按章节/主题拆分）
- 原子问答（每卡 5 条）
- 更新术语表和公式表
- 更新关系图
- 生成 P0 核实报告（如有不确定内容）

**是否生成原子问答**: 是

**是否更新关系图**: 是

**是否需要人工确认**: 是（标注不确定内容）

**是否允许进入 RAG**: 仅在 P0 核实通过后

---

### 模式 C: 当前论文材料入库

**适用**: 用户自己的论文草稿、构造笔记、证明草稿、实验数据

**处理目标**: 整理论文项目材料，识别可沉淀知识

**读取深度**:
- 识别核心构造和证明
- 识别与已有知识库的关系
- 识别待确认问题
- 不做深入理解（用户最清楚自己的论文）

**输出文件**:
- 论文项目索引
- 核心问题列表
- 待确认问题列表
- 可沉淀知识候选
- 关系依赖图
- AI 生成的一次性计划/审计/检查结果 → 放入 `11_AI工作区/`

**是否生成原子问答**: 否（论文材料应进入论文协作区，待确认后沉淀）

**是否更新关系图**: 是（标注依赖关系和待确认状态）

**是否需要人工确认**: 大量标注为 needs_human_review

**是否允许进入 RAG**: 否（论文草稿不进入公共 RAG）

---

## 模板使用说明

用户提供新论文时，请指定:
```
处理模式: A / B / C
论文路径: <path>
与当前论文关系: <related/background/dependent>
```
