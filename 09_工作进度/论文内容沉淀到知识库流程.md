# 论文内容沉淀到知识库流程

> v1 | 2026-05-04 | 论文 → 长期知识库 的反向沉淀机制

## 核心原则

```text
论文协作区不是垃圾箱。
论文会产生新知识。
但新知识不能未经验证直接进入正式知识库。
```

## 沉淀流程

```text
论文项目产生新想法/构造/证明技巧/实验结论/失败经验
  │
  ▼ 记录
论文项目 知识沉淀候选.md
  │
  ▼ 转移
11_知识入库接口/新知识候选箱.md
  │ 标记: candidate_knowledge, paper_id, needs_validation
  │
  ▼ 验证 (作者确认或后续 Batch 对照)
validated knowledge
  │
  ▼ 发布
03_FHE知识库/ (正式知识卡片、原子问答、术语、公式)
  │
  ▼ 关联
05_知识关联/ (更新概念依赖、参数关系、交叉引用)
```

## 每条沉淀知识的标准字段

```text
knowledge_id:   唯一标识 (cand_XXX)
paper_id:       来源论文 (paper_2027_eurocrypt_fhe)
idea_id:        论文内部 idea 编号
来源位置:       论文哪个部分产生 (Sec X, Experiment Y)
知识类型:       construction/proof_trick/notation/
                complexity/noise/parameter/
                implementation/negative_result/
                related_work_comparison/open_problem
当前状态:       candidate_knowledge / needs_validation /
                validated / draft_idea / deprecated
needs_human_review: true/false
已发布到KB:     true/false
反向链接:       论文项目 ↔ 知识库条目的双向引用
```

## 知识类型说明

| 类型 | 说明 | 例 |
|------|------|----|
| construction_idea | 新构造方法 | coefficient-split factorization |
| proof_trick | 可复用的证明技巧 | residue class grouping |
| notation_convention | 记号约定 | R vs R^∨ bridge |
| complexity_model | 复杂度分析框架 | leaf vs big comparison |
| noise_analysis | 噪声分析方法和 bound | ring switching noise |
| parameter_lesson | 参数选择经验 | leaf parameter selection |
| implementation_lesson | 实现经验 | gamma_impl normalization |
| negative_result | 失败尝试 | reduced-Q 当前不可行 |
| related_work_comparison | 与已有工作的对比 | vs HERMES / vs PaCo |
| open_problem | 发现的新开放问题 | reduced-Q bootstrapping |

## 重要区分

```text
论文 candidate_knowledge  ≠  外部论文 established_knowledge

论文中的 idea 需要作者验证后才算 validated。
外部论文的结论可以直接引用（标注 confidence: high）。
二者在知识库中应清晰区分。
```
