## 11. 后续作者怎么用这套流程

### 日常检索
```bash
cd 06_RAG入库准备/api_rag
python3 query_rag.py "你的问题" -k 5 -v
```

### 新增资料 → 走 5 步
1. 复制到 `01_源文件库/`
2. 分配 source_id，更新 `canonical_source_manifest.jsonl`
3. 判断是否需要精读 → 需精读则按 `新资料入库SOP.md`
4. 生成卡片/Q&A 后判断 `rag_status`
5. `rag_status=ready` → 重建 embedding + BM25

### 新增论文 idea → 走 5 步
1. 记录到当前论文项目的 `09_知识沉淀候选/`
2. 分配 idea_id
3. 更新 `candidate_knowledge总表.md`
4. 同步更新 `11_AI工作区/06_知识沉淀候选/`
5. 标记为 `candidate`（不进入 RAG ready）

### 新增 ready 卡片 → embedding 决策
- ✅ 需要重建 embedding + BM25
- 标准命令：`python3 build_embeddings.py && python3 build_bm25_index.py`
- 重建后必须 smoke test（4 条验证查询）
