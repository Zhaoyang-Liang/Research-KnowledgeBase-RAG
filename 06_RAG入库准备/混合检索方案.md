# 混合检索方案

> 版本: v1 | 生成: 2026-05-04 | 状态: 建议阶段

## 检索策略

### 第一层: 稀疏检索 (BM25)
- 快速定位关键词
- 适合术语精确匹配
- 对中文分词做优化

### 第二层: 稠密检索 (Embedding)
- 语义相似度检索
- 适合概念性、推理性问题
- BGE-large-zh 生成向量

### 混合策略
```text
BM25 (召回 top-K1) + Embedding (召回 top-K2) → 去重 → Rerank → top-N
```

其中 K1=20, K2=20, N=10

## Rerank 方案

使用 BGE-Reranker-v2-m3:
- 输入: query + top-K candidate chunks
- 输出: 按相关性重新排序
- 本地部署，无需 API
